# 浏览器眼中的所有元素都是盒子

浏览器不会把页面理解成"按钮""图片""标题"等不同对象，而是统一理解为**盒子（Box）**。

例如：

```css

<h1>ERP系统</h1>  
<p>欢迎登录</p>  
<button>登录</button>  
<img src="logo.png">
```

浏览器内部统一抽象为一个个盒子，因此 CSS 的本质就是控制这些盒子的尺寸、位置和外观。后续学习的 Flex、Grid、Position，本质上都是控制盒子的布局方式。

# 什么是盒子模型（Box Model）

```text
┌───────────────────────────────┐
│           Margin              │
│   ┌───────────────────────┐   │
│   │       Border          │   │
│   │   ┌───────────────┐   │   │
│   │   │   Padding     │   │   │
│   │   │ ┌───────────┐ │   │   │
│   │   │ │ Content   │ │   │   │
│   │   │ └───────────┘ │   │   │
│   │   └───────────────┘   │   │
│   └───────────────────────┘   │
└───────────────────────────────┘
```

每一个盒子都由四个部分组成：

```text
Margin（外边距）
    ↓
Border（边框）
    ↓
Padding（内边距）
    ↓
Content（内容区）
```

## Content（内容区）

Content 是真正存放文字、图片等内容的位置。

```css
div{
    width:300px;
    height:100px;
}
```

默认情况下：`width` 和 `height` 表示的是 **Content 的宽度和高度**，而不是整个盒子的宽高。

## Padding（内边距）

Padding 表示内容与边框之间的距离。

```css
div{
    width:300px;
    padding:20px;
}
```

浏览器计算：

```css
300(Content)
+20(left padding)
+20(right padding)
=340px
```

Padding 常用于按钮、输入框、卡片等组件，让内容距离边框更远。

##  Border（边框）

Border 位于 Padding 外侧。

```css
div{
    border:2px solid blue;
}
```

例如：

```css
width:300px;
padding:20px;
border:2px solid;
```

实际宽度：

```css
300+20+20+2+2=344px
```

## Margin（外边距）

Margin 位于盒子最外层，用于控制盒子与盒子之间的距离。

```css
button{
    margin-right:20px;
}
```


牢记：

- Padding：内容离边框远一点。
- Margin：盒子与盒子远一点。

##  浏览器如何计算盒子宽度

```css
div{
    width:300px;
    padding:20px;
    border:5px solid;
    margin:10px;
}
```

实际占据空间：`margin + border + padding + width`

```css
10 + 5 + 20 + 300 + 20 + 5 + 10 = 370px
```


## 几乎都会使用 box-sizing:border-box

默认情况下，`box-sizing:content-box;` 表示：`width = Content` ,例如：
```css
width:300px;
padding:10px;
border:1px solid;
```

那么最终宽度：300+10+10+1+1=322px

企业项目通常统一配置：

```css
*{
    box-sizing:border-box;
}
```

此时：`width = Content + Padding + Border`  整个盒子始终保持指定宽度，更符合布局直觉，也即设置了width，**整个盒子的宽度就固定了**，当调整了 padding 或者 border，对应的content就会自动的计算进行变大或者缩小。
