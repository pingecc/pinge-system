# justify-content 属性详解

`justify-content` 控制 Flex 容器内子元素在**主轴**（默认水平方向）上的对齐方式。

---

### 1. `flex-start` — 起点对齐（默认）

子元素从主轴起点开始排列，靠左对齐。

```css
.container {
  display: flex;
  justify-content: flex-start;
}
```

**效果示意：**

```
┌──────────────────────────────┐
│ [1] [2] [3]                  │
│ ▲                           │
│ 起点                        │
└──────────────────────────────┘
```

---

### 2. `center` — 居中对齐

子元素整体在主轴上居中。

```css
.container {
  display: flex;
  justify-content: center;
}
```

**效果示意：**

```
┌──────────────────────────────┐
│         [1] [2] [3]         │
│              ↑               │
│           居中               │
└──────────────────────────────┘
```

---

### 3. `flex-end` — 终点对齐

子元素从主轴终点开始排列，靠右对齐。

```css
.container {
  display: flex;
  justify-content: flex-end;
}
```

**效果示意：**

```
┌──────────────────────────────┐
│                  [1] [2] [3] │
│                           ▲  │
│                          终点 │
└──────────────────────────────┘
```

---

### 4. `space-between` — 两端对齐

- 第一个子元素贴起点，最后一个贴终点
- 中间剩余空间**平均分配**给各间隙
- 两端**没有**额外间距

```css
.container {
  display: flex;
  justify-content: space-between;
}
```

**效果示意：**

```
┌──────────────────────────────┐
│ [1]      [2]      [3]       │
│  ↑                    ↑     │
│ 起点                  终点   │
│  ←─间距─→  ←─间距─→         │
│  两端无间距                  │
└──────────────────────────────┘
```

---

### 5. `space-around` — 环绕分布

- 每个子元素**两侧**都有等量的空间
- 因此相邻子元素之间的间距 = 两端间距 × 2
- 两端**有**间距，但比中间窄

```css
.container {
  display: flex;
  justify-content: space-around;
}
```

**效果示意：**

```
┌──────────────────────────────┐
│   [1]    [2]    [3]         │
│ ←─→    ←───→    ←───→      │
│  x      2x      2x      x   │
│ 两端有间距，但中间间距是两端2倍 │
└──────────────────────────────┘
```

---

### 6. `space-evenly` — 均匀分布

- 所有间隙（包括两端）**完全相等**
- 每个子元素之间的间距 = 两端到容器的间距

```css
.container {
  display: flex;
  justify-content: space-evenly;
}
```

**效果示意：**

```
┌──────────────────────────────┐
│    [1]     [2]     [3]      │
│ ←─→    ←─→    ←─→    ←─→   │
│  x       x       x       x  │
│ 所有间隙完全相等              │
└──────────────────────────────┘
```

---

### 对比总结

| 属性 | 两端是否有间距 | 间距是否相等 |
|------|-------------|-------------|
| `flex-start` | — | — |
| `center` | — | — |
| `flex-end` | — | — |
| `space-between` | ❌ 无 | 中间相等 |
| `space-around` | ✅ 有 | 中间是两端的两倍 |
| `space-evenly` | ✅ 有 | ✅ 全部相等 |

---

### 使用场景

| 属性 | 适用场景 |
|------|---------|
| `flex-start` | 默认导航栏、列表左对齐 |
| `center` | 居中弹窗、居中按钮组 |
| `flex-end` | 右侧操作按钮、分页控件 |
| `space-between` | 两端布局（如 header 左右分布） |
| `space-around` | 等宽卡片分布、底部导航 |
| `space-evenly` | 等分按钮组、均匀分布的图标 |

---

> 💡 **注意**：以上示例默认使用 `flex-direction: row`（水平排列），主轴为水平方向。如果改为 `flex-direction: column`，主轴变为垂直方向，对齐方向也会相应变为上下对齐。
