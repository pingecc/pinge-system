## 前端思维

```text
- 页面不是程序，而是**结构树（DOM Tree）**
- CSS 不是算法，而是**盒子样式（Box Style）**
- React/Vue 不是在写 HTML，而是在**组织组件树（Component Tree）**
- 企业开发不是阅读全部源码，而是**快速定位 → 理解局部 → 修改 → 验证**
```


后端语言，其实就是在调函数，

```java
main()
 ├── login()
 │      ├── checkUser()
 │      ├── checkPassword()
 │      └── createToken()
 │
 └── queryOrder()
        ├── DAO
        └── Redis
```

你的大脑天然喜欢这种结构，因为它满足：

> 输入 → 处理 → 输出

整个程序都是：
```java

函数A  
    ↓  
函数B  
    ↓  
函数C
```

是一条时间线，因此程序员很容易理解。

但是，**HTML不是程序，它是一门描述语言，描述网页的结构**，在这个结构中只有 父子关系。
```html
body
├── header
├── main
│     ├── aside
│     └── section
└── footer
```

真正理解 HTML，不应该思考"它执行什么"，而应该思考"它是什么结构"。

CSS 也不是程序，回答的问题只有一句话：

> 每一个盒子长什么样。

后端语言展现的是调用关系，而CSS中没有调用关系，只有：

```css
选择谁？
    ↓
给什么样式？


.user {}
.user img {}
.user .title {}
```
