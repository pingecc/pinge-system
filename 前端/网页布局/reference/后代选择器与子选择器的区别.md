
在CSS中，**后代选择器（Descendant Selector）** 和 **子选择器（Child Selector）** 都用于选择嵌套在其他元素内的元素，但它们的匹配范围不同。

---

### 1. 后代选择器（Descendant Selector）

- **语法**：`A B`
- **含义**：选择**所有**在 `A` 元素内部的 `B` 元素，无论嵌套多深。
- **例子**：

```html
<div class="container">
  <p>直接子元素</p>
  <section>
    <p>嵌套更深的后代</p>
  </section>
</div>
```

```css
.container p {
  color: blue;
}
```

✅ 上面的 CSS 会将两个 `<p>` 元素都设为蓝色，因为它们都是 `.container` 的**后代**。

---

### 2. 子选择器（Child Selector）

- **语法**：`A > B`
- **含义**：只选择 `A` 元素的**直接子元素** `B`，不包括更深层的嵌套。
- **例子**：

```html
<div class="parent">
  <span>直接子元素</span>
  <div>
    <span>孙子元素</span>
  </div>
</parent>
```

```css
.parent > span {
  color: red;
}
```

✅ 这个 CSS 只会将第一个 `<span>`（直接子元素）设为红色，而不会影响嵌套在 `<div>` 里的那个 `<span>`。

---

### 对比总结

|选择器类型|语法|匹配范围|
|---|---|---|
|后代选择器|`A B`|所有嵌套层级的 `B`|
|子选择器|`A > B`|仅直接子级的 `B`|

---

如果你希望样式只作用于直接子元素，避免影响深层嵌套内容，就使用子选择器；如果想影响所有嵌套层级，则使用后代选择器。
