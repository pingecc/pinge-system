
```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>页面标题</title>
</head>
<body>
  <h1>欢迎来到我的网页</h1>
  <p>这是页面内容。</p>
</body>
</html>
```


1. `<!DOCTYPE html>`
声明文档类型，告诉浏览器这是一个 HTML5 文档。
2. `<html>`
- 作用：HTML 文档的根元素（root element），所有其他元素都必须是它的后代。
- 常用属性：
    
    - `lang`：指定页面主要语言，有助于无障碍访问和 SEO。
    ```HTML
    <html lang="zh-CN"> <!-- 简体中文 -->
    <html lang="en">   <!-- 英语 -->
    ```
1. `<head>`
- 作用：包含元数据（metadata），即“关于文档的信息”，不会直接显示在页面上。
- 可包含的内容：
    - `<title>`：页面标题（显示在浏览器标签页） `<meta charset="UTF-8">` 应尽早出现在 `<head>` 中，避免乱码。
    - `<meta>`：字符集、视口、描述、关键词等
    - `<link>`：引入 CSS、图标等
    - `<style>`：内嵌样式
    - `<script>`：通常放头部（但也可放 body 底部）
    - `<base>`：设置相对 URL 的基准
1. `<title>`
- 作用：定义文档的标题。
    
- 显示位置：
    
    - 浏览器标签页
        
    - 搜索引擎结果（SERP）
        
    - 用户收藏夹（书签）
        
- 要求：
    
    - 必须位于 `<head>` 内
        
    - 每个页面应有唯一、有意义的标题（SEO 友好）
