
# 关于空td的渲染

背景：希望利用表格做一个如下的案例，本能的通过表格合并，然后对于需要填写的单元格，使用`<td></td>`，但是发现浏览器在渲染时，对于空的单元格，宽度很小，一开始让人以为是空单元格之间的空隙。


![[Pasted image 20260531221602.png]]

```html
<body>

<table border="1" cellspacing="0">

<tr>

<th colspan="5">个人简历</th>

</tr>

  
  

<tr>

<td>姓名：</td>

<td></td>

  

<td>性别：</td>

<td></td>

  

<td rowspan="4">照片</td>

</tr>

  

<tr>

<td>婚姻状况：</td>

<td></td>

  

<td>出生年月：</td>

<td></td>

  
  

</tr>

  

<tr>

<td>民族：</td>

<td></td>

  

<td>政治面貌：</td>

<td></td>

</tr>

  

<tr>

<td>身高：</td>

<td></td>

  

<td>学历：</td>

<td></td>

</tr>

  

</table>

</body>
```

实际上这是浏览器的默认行为，由于单元格里没有内容，那么会自动调整列宽，我们可以通过**CSS来设置单元格的最小宽度**来解决。`

```CSS
<style> td { min-width: 80px; } </style>
```
