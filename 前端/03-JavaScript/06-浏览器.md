# 1. localStorage

**localStorage** 是浏览器提供的 Web Storage API 中的一种本地持久化存储机制，用于在客户端（浏览器）以键值对形式保存数据。

### 1. 核心特点

| 特性 | 说明 |
|------|------|
| **持久性** | 数据永久保存，关闭浏览器、重启电脑后依然存在，除非主动清除或用户手动删除 |
| **作用域** | 同源策略（协议 + 域名 + 端口完全相同），不同源之间无法访问 |
| **容量** | 大多数浏览器约 **5MB**（按源计算），超出抛出 `QuotaExceededError` |
| **数据类型** | **只能存字符串**。对象、数组、数字等需要先转成字符串 |
| **同步 API** | 所有操作都是同步的，会阻塞主线程（大数据时需注意性能） |
| **不随请求发送** | 与 Cookie 不同，不会自动附加到 HTTP 请求中 |

对比：
- **sessionStorage**：同样是同源、字符串存储，但标签页关闭后数据消失。
- **Cookie**：容量小（约 4KB）、会随请求发送、有过期时间、可设置 HttpOnly 等安全属性。

### 2. 常用 API

```js
// 1. 存储数据
localStorage.setItem('key', 'value');

// 2. 读取数据（不存在返回 null）
const value = localStorage.getItem('key');

// 3. 删除指定键
localStorage.removeItem('key');

// 4. 清空当前源下所有数据
localStorage.clear();

// 5. 获取第 n 个键名（按插入顺序，0 开始）
const keyName = localStorage.key(0);

// 6. 获取当前存储的键值对数量
const count = localStorage.length;
```

也可以直接用属性方式（不推荐正式项目，容易与方法冲突）：

```js
localStorage.username = 'Grok';
console.log(localStorage.username);
delete localStorage.username;
```

### 3. 存储非字符串数据（最常用场景）

因为只能存字符串，对象/数组必须用 `JSON`：

```js
const user = {
  id: 1001,
  name: '张三',
  roles: ['admin', 'editor'],
  lastLogin: new Date().toISOString()
};

// 存
localStorage.setItem('user', JSON.stringify(user));

// 取
const stored = localStorage.getItem('user');
const parsedUser = stored ? JSON.parse(stored) : null;

console.log(parsedUser?.name); // 张三
```

**注意**：
- `JSON.stringify` 会丢失 `undefined`、函数、Symbol、循环引用等。
- `Date` 对象会被转成字符串，取出来需要重新 `new Date()`。
- 大对象序列化/反序列化有性能开销。

### 4. 监听存储变化（跨标签页通信）

当**同一个源的其他标签页/窗口**修改了 localStorage 时，当前页面会触发 `storage` 事件：

```js
window.addEventListener('storage', (event) => {
  console.log('key:', event.key);
  console.log('oldValue:', event.oldValue);
  console.log('newValue:', event.newValue);
  console.log('url:', event.url);          // 触发修改的页面 URL
  console.log('storageArea:', event.storageArea); // localStorage 对象本身
});
```

**重要限制**：
- 只有**其他**文档修改时才会触发，当前页面自己 `setItem`/`removeItem` **不会**触发。
- 需要同源。

这是实现简单跨标签页同步的常用手段（例如登录状态同步、购物车更新）。

### 5. 容量与错误处理

```js
try {
  localStorage.setItem('bigData', hugeString);
} catch (e) {
  if (e.name === 'QuotaExceededError') {
    console.error('存储空间已满');
    // 可以做清理旧数据、压缩、提示用户等处理
  } else {
    throw e;
  }
}
```

实际可用容量会因浏览器、设备、已有数据而略有差异，不要依赖精确的 5MB。
> 目前绝大多数浏览器的存储限制基本是 5MB
### 6. 安全与最佳实践

1. **不要存敏感信息**  
   localStorage 任何同源的 JS 都能读写，XSS 攻击一旦成功即可轻易窃取。密码、token（尤其是长期有效的）、身份证号等应放在 HttpOnly Cookie 或更安全的地方。

2. **XSS 风险**  
   永远不要把用户输入的内容未经转义就直接写入，也要避免 `eval`/`innerHTML` 等危险操作。

3. **版本管理**  
   数据结构变更时，建议在数据里加版本号，读取时做迁移：

   ```js
   const data = JSON.parse(localStorage.getItem('appData') || '{}');
   if (data.version !== 2) {
     // 迁移逻辑
     data.version = 2;
     localStorage.setItem('appData', JSON.stringify(data));
   }
   ```

4. **命名规范**  
   使用有意义的前缀，避免与其他库冲突，例如 `myapp_user_settings`。

5. **性能注意**  
   - 避免频繁读写大对象。
   - 不要在循环里反复 `getItem`/`setItem`。
   - 可考虑用内存缓存 + 防抖写入。

6. **隐私模式 / 无痕模式**  
   大多数浏览器在隐私模式下仍然支持 localStorage，但关闭窗口后数据会被清除（行为因浏览器而异）。

7. **清理时机**  
   用户退出登录、切换账号时，应主动 `removeItem` 或 `clear` 相关数据。


---

**总结**：localStorage 适合存储用户偏好、主题、临时草稿、非敏感缓存等数据。它简单、持久、同源隔离，但要注意字符串限制、容量、XSS 风险和同步阻塞特性。真正需要更强能力时，可以考虑 IndexedDB（异步、支持大容量和复杂查询）。

# location
 `location` 是 JavaScript 中用于**获取和操作当前页面 URL** 的核心对象。它挂载在 `window` 下（即 `window.location`），也可以简写为 `location`。

---

## 核心属性

`location` 将当前 URL 拆解为多个可读写的属性：

| 属性 | 说明 | 示例（URL: `https://example.com:8080/path?a=1&b=2#section`）|
|------|------|------|
| `href` | 完整 URL | `https://example.com:8080/path?a=1&b=2#section` |
| `protocol` | 协议（含冒号） | `https:` |
| `host` | 主机名 + 端口 | `example.com:8080` |
| `hostname` | 主机名（不含端口） | `example.com` |
| `port` | 端口号 | `8080` |
| `pathname` | 路径部分 | `/path` |
| `search` | 查询参数（含问号） | `?a=1&b=2` |
| `hash` | 锚点（含井号） | `#section` |
| `origin` | 协议 + 主机 + 端口（只读） | `https://example.com:8080` |

 代码示例
```javascript
console.log(location.href);      // 完整地址
console.log(location.pathname);  // /path
console.log(location.search);    // ?a=1&b=2
```

---

## 常用方法

| 方法 | 作用 | 特点 |
|------|------|------|
| `assign(url)` | 跳转到新页面 | 会在浏览器历史中留下记录（可后退） |
| `replace(url)` | 替换当前页面 | **不会**留下历史记录（不可后退） |
| `reload(force)` | 刷新页面 | `true` 强制从服务器刷新；`false` 或空则优先用缓存 |
| `toString()` | 返回 `href` | 同 `location.href` |

代码示例
```javascript
// 跳转（可后退）
location.assign('https://example.com');

// 替换（不可后退，适合登录后跳转）
location.replace('/dashboard');

// 刷新
location.reload();        // 普通刷新
location.reload(true);    // 强制刷新（类似 Ctrl+F5）
```

---

## 实际应用场景

### 1. 页面跳转
```javascript
// 最常用
location.href = 'https://example.com';

// 等价于
window.location = 'https://example.com';
```

### 2. 解析 URL 参数
传统写法：
```javascript
const params = new URLSearchParams(location.search);
console.log(params.get('a'));  // "1"
```

### 3. 修改 URL 但不刷新（现代用法）
配合 `history.pushState` 可实现无刷新修改地址栏：
```javascript
history.pushState({}, '', '/new-path');
// 此时 location.pathname 会变为 /new-path，但页面不会刷新
```

### 4. 获取当前域名做判断
```javascript
if (location.hostname === 'localhost') {
  // 本地开发环境配置
}
```

# 2. 浏览器中的「同源」（Origin）

**源**是浏览器用来识别一个网页身份的基本单位，由以下三部分**严格组合**而成：

```
协议（Protocol） + 域名（Domain） + 端口（Port）
```

只要这三部分**完全相同**，就属于同一个源。

#### 举例说明：

| URL | 协议 | 域名 | 端口 | 源是否相同？ |
|-----|------|------|------|-------------|
| `https://www.example.com` | https | www.example.com | 443（默认） | 基准 |
| `https://www.example.com/page` | https | www.example.com | 443 | **同源** |
| `https://www.example.com:443` | https | www.example.com | 443 | **同源** |
| `http://www.example.com` | http | www.example.com | 80 | **不同源**（协议不同） |
| `https://example.com` | https | example.com | 443 | **不同源**（域名不同） |
| `https://api.example.com` | https | api.example.com | 443 | **不同源**（子域名不同） |
| `https://www.example.com:8080` | https | www.example.com | 8080 | **不同源**（端口不同） |
| `https://www.example.com:443` | https | www.example.com | 443 | **同源** |

**注意**：
- 端口如果不写，浏览器会使用协议的默认端口（http 是 80，https 是 443）。
- 路径（`/page`）、查询参数（`?id=1`）、锚点（`#section`）**都不影响源**。
- `www.example.com` 和 `example.com` 被视为**不同源**（除非做了特殊配置）。

### 2. 什么是「同源」（Same-Origin）？

当两个页面的**协议 + 域名 + 端口完全一致**时，就称为**同源**。

同源的页面之间可以：
- 互相访问对方的 DOM
- 共享 `localStorage` / `sessionStorage`
- 发送 AJAX / Fetch 请求（默认允许）
- 读写对方的 Cookie（在符合路径和域名规则的前提下）

### 3. 什么是「同源策略」（Same-Origin Policy）？

这是浏览器最核心的安全机制之一。

**同源策略规定**：一个源的脚本，默认**不能**访问另一个源的资源。

它主要限制以下行为：

| 受限操作 | 说明 |
|---------|------|
| DOM 访问 | 无法读取其他源页面的 HTML 元素 |
| localStorage / sessionStorage | 无法读写其他源的数据 |
| Cookie | 默认无法访问其他源的 Cookie |
| AJAX / Fetch | 默认无法向其他源发请求（会被 CORS 拦截） |
| iframe 内容 | 无法直接操作跨源 iframe 里的内容 |

**目的**：防止恶意网站通过脚本窃取其他网站的用户数据（比如银行页面的 Cookie、表单内容等）。

### 4. 实际例子

假设当前页面是：`https://www.example.com`

```js
// 同源，可以正常访问
localStorage.setItem('theme', 'dark');          // 成功
document.getElementById('xxx');                 // 成功
fetch('/api/user');                             // 成功（相对路径）

// 不同源，会被拦截
localStorage.getItem('theme');                  // 访问不了其他源的数据
fetch('https://api.example.com/data');          // 会被 CORS 策略拦截（除非对方允许）
document.querySelector('iframe').contentWindow.document; // 跨源 iframe 无法访问
```

### 5. 如何突破同源限制？（常见合法方式）

虽然有同源策略，但现代 Web 有标准的跨源通信方式：

1. **CORS**（Cross-Origin Resource Sharing）  
   服务器通过响应头明确允许哪些源可以访问。

2. **postMessage**  
   不同源的窗口/iframe 之间安全通信。

3. **JSONP**（已过时，不推荐）

4. **代理**  
   通过自己的服务器转发请求，绕过浏览器限制。

5. **document.domain**（已基本废弃，且限制很多）

---

**总结一句话**：

> **源 = 协议 + 域名 + 端口**  
> **同源 = 这三部分完全一样**  
> **同源策略 = 浏览器为了安全，默认禁止不同源之间随意访问资源**

这就是为什么之前说 localStorage 的数据是「按源隔离」的——不同源之间完全看不到对方的 localStorage。

# 3. 给 DOM 元素绑定事件回调函数

```text
DOM 元素  ───── 监听 ─────>  事件
   │                           │
   │                           │ 触发
   │                           ↓
   └───── 绑定 ─────>  回调函数（被调用）
```

- **DOM 元素** 是载体
- **事件** 是触发条件
- **回调函数** 是响应动作

在某个 DOM 元素上，监听某个事件，当这个事件发生时，就执行你注册的回调函数。



## 核心 API：`addEventListener`

语法：

```js
element.addEventListener(事件类型, 回调函数, 可选配置);
```

- **第一个参数**：事件类型（字符串），如 `'click'`、`'submit'`、`'DOMContentLoaded'`
- **第二个参数**：回调函数（普通函数或箭头函数）
- **第三个参数**（可选）：
  - 布尔值：`true` 表示在捕获阶段触发，`false`（默认）表示在冒泡阶段触发
  - 或对象：`{ capture: false, once: false, passive: false }`

### 2. 绑定过程本质

1. 你拿到一个 DOM 元素（通过 `getElementById`、`querySelector` 等）
2. 调用它的 `addEventListener` 方法
3. 浏览器在内部给这个元素的对应事件，**添加一个监听器记录**
4. 当这个事件真正发生时，浏览器会**按注册顺序**依次调用所有对应的回调函数，并传入一个 `Event` 对象

注意：
- 注册时**不会立刻执行**回调函数
- 只有事件真实触发时才会执行
- 同一个元素、同一个事件可以绑定多个回调（都会执行）

### 3. 回调函数被调用时会发生什么

浏览器调用你的回调时，大致是这样：

```js
回调函数(event对象);
```

`event` 对象里包含：
- `event.target`：真正触发事件的元素
- `event.currentTarget`：当前正在处理事件的元素（绑定时的那个）
- `event.type`：事件类型
- `event.preventDefault()`：阻止默认行为
- `event.stopPropagation()`：阻止事件继续传播

### 4. 事件传播的两个阶段（了解即可）

事件触发后会经历：

1. **捕获阶段**：从 `window` → `document` → 父元素 → … → 目标元素
2. **目标阶段**：到达真正触发的元素
3. **冒泡阶段**：从目标元素 → 父元素 → … → `document` → `window`

默认情况下，`addEventListener` 监听的是**冒泡阶段**。

### 5. 如何取消绑定

```js
element.removeEventListener(事件类型, 同一个回调函数引用);
```

注意：必须传入**同一个函数引用**才能移除，匿名函数通常无法移除。

### 6. 现代推荐写法 vs 旧写法

| 写法 | 示例 | 说明 |
|------|------|------|
| 推荐 | `element.addEventListener('click', handler)` | 可绑定多个、可移除、功能完整 |
| 旧写法 | `element.onclick = handler` | 只能绑一个，会覆盖 |
| HTML 属性 | `<button onclick="...">` | 不推荐，耦合严重 |

## 常用事件
### 1. 文档 / 窗口相关事件

#### `DOMContentLoaded`（DOM 加载完成）
```js
document.addEventListener('DOMContentLoaded', () => {
  console.log('DOM 已准备好，可以安全操作元素了');
  const btn = document.getElementById('myBtn');
  // 在这里绑定其他事件最合适
});
```

#### `load`（页面所有资源加载完成）
```js
window.addEventListener('load', () => {
  console.log('图片、CSS、JS 全部加载完成');
});
```

#### `beforeunload`（即将离开页面）
```js
window.addEventListener('beforeunload', (event) => {
  // 现代浏览器只会显示通用提示，不能自定义文案
  event.preventDefault();
  event.returnValue = ''; // 兼容旧浏览器
});
```

#### `resize`（窗口大小改变）
```js
window.addEventListener('resize', () => {
  console.log('当前窗口宽度：', window.innerWidth);
});
```

#### `scroll`（页面滚动）
```js
window.addEventListener('scroll', () => {
  console.log('滚动距离：', window.scrollY);
});
```

---

### 2. 鼠标事件

#### `click`（单击）
```js
const btn = document.getElementById('myBtn');
btn.addEventListener('click', (event) => {
  console.log('按钮被点击了', event.target);
});
```

#### `dblclick`（双击）
```js
btn.addEventListener('dblclick', () => {
  console.log('按钮被双击了');
});
```

#### `mousedown` / `mouseup`（按下 / 松开）
```js
btn.addEventListener('mousedown', () => {
  console.log('鼠标按下');
});
btn.addEventListener('mouseup', () => {
  console.log('鼠标松开');
});
```

#### `mousemove`（鼠标移动）
```js
document.addEventListener('mousemove', (event) => {
  console.log(`鼠标位置：x=${event.clientX}, y=${event.clientY}`);
});
```

#### `mouseenter` / `mouseleave`（进入 / 离开，不冒泡）
```js
const box = document.getElementById('box');
box.addEventListener('mouseenter', () => {
  box.style.backgroundColor = 'lightblue';
});
box.addEventListener('mouseleave', () => {
  box.style.backgroundColor = '';
});
```

#### `contextmenu`（右键菜单）
```js
box.addEventListener('contextmenu', (event) => {
  event.preventDefault(); // 阻止浏览器默认右键菜单
  console.log('自定义右键菜单可以在这里弹出');
});
```

---

### 3. 键盘事件

#### `keydown`（按键按下）
```js
document.addEventListener('keydown', (event) => {
  console.log('按下了键：', event.key); // 如 'Enter'、'a'、'Escape'
  
  if (event.key === 'Enter') {
    console.log('用户按了回车');
  }
  if (event.ctrlKey && event.key === 's') {
    event.preventDefault();
    console.log('拦截了 Ctrl + S');
  }
});
```

#### `keyup`（按键松开）
```js
document.addEventListener('keyup', (event) => {
  console.log('松开了键：', event.key);
});
```

---

### 4. 表单相关事件（最常用）

#### `submit`（表单提交）
```js
const form = document.getElementById('login-form');
form.addEventListener('submit', (event) => {
  event.preventDefault(); // 阻止表单真正提交（页面刷新）
  
  const username = form.username.value;
  console.log('准备提交用户名：', username);
  // 这里做校验或发送请求
});
```

#### `input`（输入内容实时变化）
```js
const input = document.getElementById('username');
input.addEventListener('input', (event) => {
  console.log('当前输入值：', event.target.value);
});
```

#### `change`（值改变且失去焦点 / 选择改变）
```js
const select = document.getElementById('city');
select.addEventListener('change', (event) => {
  console.log('选择了：', event.target.value);
});

const checkbox = document.getElementById('remember');
checkbox.addEventListener('change', (event) => {
  console.log('复选框状态：', event.target.checked);
});
```

#### `focus` / `blur`（获得 / 失去焦点）
```js
input.addEventListener('focus', () => {
  console.log('输入框获得焦点');
  input.style.borderColor = 'blue';
});
input.addEventListener('blur', () => {
  console.log('输入框失去焦点');
  input.style.borderColor = '';
});
```

#### `reset`（表单重置）
```js
form.addEventListener('reset', () => {
  console.log('表单被重置了');
});
```

### 5. 其他常用事件

#### `error`（资源加载失败）
```js
const img = document.getElementById('avatar');
img.addEventListener('error', () => {
  img.src = 'default-avatar.png'; // 加载失败时显示默认图

```

#### `transitionend`（CSS 过渡结束）
```js
box.addEventListener('transitionend', () => {
  console.log('过渡动画结束了');
});
```

#### `animationend`（CSS 动画结束）
```js
box.addEventListener('animationend', () => {
  console.log('动画播放完毕');
});
```

#### 触摸事件（移动端）
```js
box.addEventListener('touchstart', (event) => {
  console.log('手指按下', event.touches[0].clientX);
});
box.addEventListener('touchmove', (event) => {
  console.log('手指移动');
});
box.addEventListener('touchend', () => {
  console.log('手指离开');
});
```



### 6. 实际开发中的建议

1. **优先使用 `addEventListener`**，不要用 `onclick =` 或 HTML 属性。
2. **`DOMContentLoaded` 是初始化页面逻辑的最佳时机**（你代码的做法是正确的）。
3. **表单提交一定要监听 `submit` 事件**，并调用 `event.preventDefault()`，而不是只监听按钮的 `click`。
4. **高频事件**（`scroll`、`resize`、`mousemove`、`input`）要注意性能，必要时做防抖（debounce）或节流（throttle）。
5. **能用事件委托就用事件委托**（把事件绑在父元素上，利用冒泡），减少监听器数量。

# DOM操作

 在网页开发中，**DOM（Document Object Model，文档对象模型）** 是 JavaScript 与 HTML 页面交互的核心桥梁。掌握 DOM 操作是前端开发的基础。下面按功能模块系统讲解。

---

## 一、获取元素（查询 DOM）

### 1. 通过 ID 获取（单个元素）
```javascript
const el = document.getElementById('header');
// 返回单个 Element 或 null
// 注意：参数不加 #，且 id 在页面中应唯一
```

### 2. 通过类名获取（元素集合）
```javascript
const items = document.getElementsByClassName('item');
// 返回 HTMLCollection（实时集合，动态更新）
// 即使只有一个元素，也是集合，需用 items[0] 访问
```

### 3. 通过标签名获取
```javascript
const divs = document.getElementsByTagName('div');
const inputs = form.getElementsByTagName('input');
// 同样返回 HTMLCollection
```

### 4. 通过 name 属性获取（常用于表单）
```javascript
const radios = document.getElementsByName('gender');
// 返回 NodeList
```

### 5. CSS 选择器方式（最灵活，现代首选）
```javascript
// 获取第一个匹配元素
const first = document.querySelector('.list .item');

// 获取所有匹配元素
const all = document.querySelectorAll('.item');
// 返回 NodeList（静态集合，不随 DOM 变化自动更新）
```

> **HTMLCollection vs NodeList 的区别：**
> - `HTMLCollection`（`getElementsBy*` 返回）是**实时的**，DOM 变化会自动反映
> - `NodeList`（`querySelectorAll` 返回）是**静态的**，获取时的快照，后续 DOM 变化不影响它

---

## 二、创建与添加元素

### 1. 创建元素
```javascript
const div = document.createElement('div');
const text = document.createTextNode('Hello');
```

### 2. 添加到 DOM
```javascript
const parent = document.getElementById('container');

// 在末尾追加
parent.appendChild(div);

// 在指定子元素前插入
parent.insertBefore(div, referenceChild);

// 现代方法（更灵活，推荐）
parent.append(div, '文本');        // 末尾追加，可多个
parent.prepend(div);               // 开头插入
referenceChild.before(div);        // 在某元素之前
referenceChild.after(div);         // 在某元素之后
referenceChild.replaceWith(div);   // 替换某元素
```

### 3. 克隆元素
```javascript
const clone = original.cloneNode(true);  
// true = 深克隆（含子元素）；false = 浅克隆（仅自身）
```

---

## 三、修改元素内容

### 1. `textContent` — 纯文本（推荐）
```javascript
el.textContent = '<script>alert(1)</script>';
// 输出原样文本，不会执行脚本（XSS 安全）
```

### 2. `innerText` — 渲染后的文本
```javascript
el.innerText = 'Hello';
// 会触发重排（reflow），性能略差；受 CSS 影响（如 display:none 的内容获取不到）
```

### 3. `innerHTML` — HTML 字符串（慎用）
```javascript
el.innerHTML = '<strong>加粗</strong>';
// 会解析 HTML；如果内容来自用户输入，极易引发 XSS 攻击
```

### 4. `outerHTML` — 包含自身标签
```javascript
console.log(el.outerHTML);  
// 输出：<div id="x">内容</div>
```

> **安全提示：** 插入用户输入内容时，优先用 `textContent`，或使用 `innerHTML` 前做好转义过滤。

---

## 四、修改元素属性

### 1. 标准属性
```javascript
const img = document.getElementById('pic');

img.src = 'photo.jpg';           // 直接属性赋值
img.alt = '描述文字';
img.id = 'new-id';
img.className = 'active';        // class 是保留字，用 className
```

### 2. 通用方法（适合自定义属性或动态属性名）
```javascript
img.setAttribute('src', 'photo.jpg');
img.getAttribute('src');         // 'photo.jpg'
img.hasAttribute('data-id');     // true / false
img.removeAttribute('title');
```

### 3. 自定义数据属性（data-*）
HTML5 推荐用 `data-` 前缀存放自定义数据：
```html
<div id="user" data-user-id="123" data-role="admin">...</div>
```
```javascript
const user = document.getElementById('user');

// 通过 dataset 对象访问（自动驼峰命名）
console.log(user.dataset.userId);   // "123"
console.log(user.dataset.role);     // "admin"

// 修改
user.dataset.status = 'online';
```

---

## 五、修改元素样式

### 1. 行内样式（style 属性）
```javascript
const box = document.getElementById('box');

box.style.width = '200px';
box.style.backgroundColor = '#f00';  // CSS 属性转驼峰命名
box.style.cssText = 'width:200px; height:100px; color:red;';  // 批量设置
```

### 2. 操作 CSS 类（现代推荐方式）
```javascript
const el = document.getElementById('menu');

// 添加类
el.classList.add('open', 'active');

// 移除类
el.classList.remove('hidden');

// 切换类（有则移除，无则添加）
el.classList.toggle('active');

// 判断是否包含类
if (el.classList.contains('active')) {
    // ...
}

// 替换类
el.classList.replace('old-class', 'new-class');
```

> **为什么推荐用 `classList` 而不是直接修改 `className`？**
> `className` 会覆盖整个 class 字符串，而 `classList` 可以精确增删，不会误删其他类。

const child = document.getElementById('old');

// 方法1：通过父元素移除（传统）
child.parentNode.removeChild(child);

child.remove();

## 七、DOM 遍历（导航关系）

通过元素间的父子、兄弟关系导航：

```javascript
const el = document.getElementById('current');

// 父节点
el.parentNode;           // 可能返回文本节点等
el.parentElement;        // 只返回元素节点（更常用）

// 子节点
el.childNodes;           // 所有子节点（含文本、注释）— NodeList
el.children;             // 仅子元素节点 — HTMLCollection
el.firstChild;           // 第一个子节点（可能是文本）
el.firstElementChild;    // 第一个子元素
el.lastElementChild;     // 最后一个子元素

// 兄弟节点
el.nextSibling;          // 下一个兄弟节点
el.nextElementSibling;   // 下一个兄弟元素
el.previousElementSibling; // 上一个兄弟元素
```

## 八、元素尺寸与位置（几何属性）

```javascript
const box = document.getElementById('box');

// 元素自身尺寸（不含外边距）
box.clientWidth;     // 内容宽 + padding（不含边框和滚动条）
box.clientHeight;    // 内容高 + padding
box.offsetWidth;     // 内容宽 + padding + border（含滚动条）
box.offsetHeight;    // 内容高 + padding + border

// 相对于 offsetParent 的位置
box.offsetLeft;
box.offsetTop;

// 滚动
box.scrollTop;       // 元素内部已滚动的高度
box.scrollHeight;    // 元素内容的总高度（含溢出部分）

// 获取相对于视口的位置（现代精确方法）
const rect = box.getBoundingClientRect();
rect.top;      // 元素顶部到视口顶部的距离
rect.left;     // 元素左边到视口左边的距离
rect.width;    // 元素总宽
rect.height;   // 元素总高
```

## 九、DOM 事件操作

### 1. 添加事件监听（现代标准方式）
```javascript
const btn = document.getElementById('btn');

btn.addEventListener('click', function(event) {
    console.log('被点击了');
    console.log(event.target);  // 实际被点击的元素
    event.preventDefault();     // 阻止默认行为（如链接跳转）
    event.stopPropagation();    // 阻止事件冒泡
});
```

### 2. 事件委托（性能优化技巧）
利用冒泡机制，在父元素上统一监听：
```javascript
document.getElementById('list').addEventListener('click', function(e) {
    if (e.target.tagName === 'LI') {
        console.log('点击了列表项：', e.target.textContent);
    }
});
```

### 3. 移除事件监听
```javascript
function handler() { /* ... */ }

btn.addEventListener('click', handler);
btn.removeEventListener('click', handler);  // 移除时必须引用同一函数
```

## 十、现代 DOM API（进阶）

### 1. `insertAdjacentHTML` / `insertAdjacentElement`
在元素相对位置插入内容，性能优于 `innerHTML` 重新解析整个元素：
```javascript
el.insertAdjacentHTML('beforebegin', '<p>前面</p>');  // 元素之前
el.insertAdjacentHTML('afterbegin', '<span>内部开头</span>');  // 内部最前
el.insertAdjacentHTML('beforeend', '<span>内部末尾</span>');   // 内部最后
el.insertAdjacentHTML('afterend', '<p>后面</p>');    // 元素之后
```

### 2. `closest` — 向上查找祖先
```javascript
const btn = e.target;
const card = btn.closest('.card');  // 向上查找最近的含 .card 的祖先元素
```

### 3. `matches` — 判断是否匹配选择器
```javascript
if (el.matches('.active')) {
    // 元素是否有 active 类
}
```

### 4. `contains` — 判断是否包含某元素
```javascript
const parent = document.getElementById('parent');
const child = document.getElementById('child');
console.log(parent.contains(child));  // true / false
```

## 十一、性能优化要点

| 优化策略 | 说明 |
|---------|------|
| **减少重排（Reflow）** | 频繁修改样式时，先隐藏/离线修改，再显示；或使用 `cssText` 批量修改 |
| **缓存查询结果** | 不要重复查询同一元素，先保存到变量 |
| **使用文档片段（DocumentFragment）** | 批量插入元素时，先在内存中组装，再一次性插入 DOM |
| **事件委托** | 避免给大量子元素分别绑定事件 |
| **优先用 `classList`** | 代替直接修改 `style`，让样式归 CSS 管理 |

### 文档片段示例
```javascript
const fragment = document.createDocumentFragment();
for (let i = 0; i < 100; i++) {
    const li = document.createElement('li');
    li.textContent = `Item ${i}`;
    fragment.appendChild(li);
}
document.getElementById('list').appendChild(fragment);  // 只触发一次重排
```
