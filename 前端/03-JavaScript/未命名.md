TypeScript（简称 TS） 是由微软开发的一种开源、免费的编程语言。它是 JavaScript 的超集（superset），在 JavaScript 的基础上增加了 静态类型系统（Static Typing） 和其他一些现代语言特性，使得大型项目更易于维护、调试和协作。

> "超集": 在数学和编程语言中，A 是 B 的超集，意味着：B 中的所有内容都包含在 A 中，而 A 还可能有额外的东西。应用到 TypeScript 和 JavaScript 上就是：**所有合法的 JavaScript 代码，都是合法的 TypeScript 代码。** **➕ TypeScript 在此基础上增加了新特性（主要是类型系统等）。**

环境配置

编写 的TypeScript 代码，使用 TypeScript 编译器将 TypeScript 代码编译成纯 JavaScript 代码。获得纯 JavaScript 代码后，可以将其部署到任何 JavaScript 运行的环境中。TypeScript 文件使用 `.ts` 扩展名。

下载TypeScript编译器：是一个Node.js模块

```Bash
# 安装typescript编译器模块
npm install -g typescript
# 查看版本
tsc --v

# 编译 ts文件 会生成对应的demo.js
tsc demo.ts
# 再运行demo.js
node demp.js

# 如果希望在Node.js上直接运行typeScript代码，无需预编译，则可以按照tsx模块
npm install -g tsx

# 直接运行demo.ts
tsx demo.ts
```
