# 变量声明

```JavaScript
// 推荐写法（ES6+）
let age = 25;           // 可变变量
const PI = 3.14;        // 常量（优先使用）
let name = "张三";

// 旧写法（尽量少用）
var oldVar = "不推荐";
```

**和 Java 的对比**：
- let ≈ Java 的局部变量
- const ≈ final（但对象内容仍可变）
- 没有类型声明，类型是运行时决定的（动态类型）
- var 有函数作用域和变量提升问题，现代代码几乎不用

## 模板字符串

```javaScript
const name = "张三";
const age = 28;

// 传统写法（拼接很麻烦）

              "  <h1>标题</h1>\n" +
              "  <p>内容</p>\n" +
              "</div>";

<div>
  <h1>标题</h1>
  <p>内容</p>
</div>

```

- 使用反引号 ` 包裹

# 解构

解构（Destructuring） 是 ES6 引入的语法，可以方便地从数组或对象中提取值，并赋值给变量。

## 1. 数组解构

```js
const arr = [1, 2, 3, 4, 5];

// 基本用法
const [a, b, c] = arr;
console.log(a, b, c); // 1 2 3

// 跳过某些元素
const [x, , y] = arr;
console.log(x, y); // 1 3

// 剩余元素（rest）
const [first, ...rest] = arr;
console.log(first); // 1
console.log(rest);  // [2, 3, 4, 5]

// 默认值
const [m, n = 10, p = 20] = [5];
console.log(m, n, p); // 5 10 20
```

**交换变量**（经典用法）：
```js
let a = 1, b = 2;
[a, b] = [b, a];
console.log(a, b); // 2 1
```

## 2. 对象解构

```js
const person = {
  name: '张三',
  age: 25,
  city: '北京'
};

// 基本用法
const { name, age } = person;
console.log(name, age); // 张三 25

// 重命名变量
const { name: userName, age: userAge } = person;
console.log(userName, userAge); // 张三 25

// 默认值
const { name, gender = '男' } = person;
console.log(gender); // 男

// 剩余属性
const { name, ...others } = person;
console.log(others); // { age: 25, city: '北京' }
```

## 3. 嵌套解构

```js
const user = {
  id: 1,
  info: {
    name: '李四',
    address: {
      city: '上海',
      street: '南京路'
    }
  }
};

const {
  info: {
    name,
    address: { city }
  }
} = user;

console.log(name, city); // 李四 上海
```

数组也可以嵌套：
```js
const nested = [1, [2, 3], 4];
const [a, [b, c], d] = nested;
console.log(a, b, c, d); // 1 2 3 4
```

## 4. 函数参数解构

这是非常实用的场景：

```js
// 对象参数解构 + 默认值
function greet({ name = '匿名', age = 18 } = {}) {
  console.log(`你好，${name}，今年${age}岁`);
}

greet({ name: '王五', age: 30 }); // 你好，王五，今年30岁
greet();                          // 你好，匿名，今年18岁

// 数组参数解构
function sum([a, b, c = 0]) {
  return a + b + c;
}
console.log(sum([1, 2])); // 3
```

## 5. 实际常用场景

**从函数返回多个值**：
```js
function getUser() {
  return { id: 1, name: '赵六', role: 'admin' };
}
const { name, role } = getUser();
```

**配合 API 数据**：
```js
const response = {
  data: {
    user: { name: '小明', age: 20 },
    token: 'abc123'
  }
};

const {
  data: {
    user: { name },
    token
  }
} = response;
```

**在循环中使用**：
```js
const users = [
  { id: 1, name: 'A' },
  { id: 2, name: 'B' }
];

for (const { id, name } of users) {
  console.log(id, name);
}
```

## 6.注意事项

1. **声明方式**：解构赋值时如果变量已经声明过，需要加括号（否则会被解析为代码块）：
   
   ```js
   let a, b;
   ({ a, b } = { a: 1, b: 2 }); // 注意外层的括号
   ```
   
2. **右侧必须是可迭代对象**（数组）或对象，`null`/`undefined` 会报错。

3. **对象解构时属性名必须匹配**（除非使用重命名）。

解构让代码更简洁、可读性更强，是现代 JavaScript 中非常常用的特性。



# 展开运算符

JavaScript 中的**展开运算符（Spread Operator）**是三个点 `...`，它可以将一个可迭代对象（如数组、字符串）或对象字面量"展开"为多个元素。

## 数组展开

### 1. 数组合并
```javascript
const arr1 = [1, 2];
const arr2 = [3, 4];
const merged = [...arr1, ...arr2]; // [1, 2, 3, 4]
```

### 2. 数组复制（浅拷贝）
```javascript
const original = [1, 2, 3];
const copy = [...original]; // [1, 2, 3]
copy.push(4);
console.log(original); // [1, 2, 3] — 原数组不受影响
```

### 3. 在数组中间插入
```javascript
const nums = [2, 3];
const withInsert = [1, ...nums, 4]; // [1, 2, 3, 4]
```

### 4. 字符串转数组
```javascript
const chars = [..."hello"]; // ['h', 'e', 'l', 'l', 'o']
```

## 对象展开（ES2018）

### 1. 对象合并
```javascript
const obj1 = { a: 1, b: 2 };
const obj2 = { c: 3 };
const merged = { ...obj1, ...obj2 }; // { a: 1, b: 2, c: 3 }
```

### 2. 对象复制（浅拷贝）
```javascript
const user = { name: "Tom", age: 20 };
const copy = { ...user };
```

### 3. 覆盖/添加属性
```javascript
const user = { name: "Tom", age: 20 };
const updated = { ...user, age: 21, city: "Beijing" };
// { name: "Tom", age: 21, city: "Beijing" }
```

> ⚠️ **注意**：对象展开时，后面的同名属性会覆盖前面的。
> ```javascript
> const a = { x: 1, y: 2 };
> const b = { y: 3, z: 4 };
> const c = { ...a, ...b }; // { x: 1, y: 3, z: 4 }
> ```

## 函数调用时展开参数

将数组展开为函数的独立参数：

```javascript
const nums = [1, 2, 3];
console.log(Math.max(...nums)); // 3，等同于 Math.max(1, 2, 3)

// 之前没有展开运算符时：
console.log(Math.max.apply(null, nums));
```

## 五、注意事项

1. **只能展开可迭代对象**：数组、字符串、Set、Map、类数组（如 NodeList）可以展开；普通对象不能直接用于数组上下文（但可以在对象字面量中展开对象）。

2. **浅拷贝**：展开运算符做的是浅拷贝，嵌套对象/数组仍然共享引用。
   ```javascript
   const a = [{ x: 1 }];
   const b = [...a];
   b[0].x = 2;
   console.log(a[0].x); // 2 — 嵌套对象被修改了
   ```

3. **对象展开不复制原型链**：只复制对象自身的可枚举属性。





# 剩余参数

**剩余参数（Rest Parameters）**是 ES6 引入的语法，用 `...` 把函数的“剩余”参数收集成一个真正的数组。

### 基本语法

```js
function 函数名(普通参数, ...剩余参数) {
  // 剩余参数是一个数组
}
```

- `...` 只能写在**参数列表的最后一位**。
- 它会把从当前位置开始的所有实参收集成一个**数组**。
- 如果没有多余参数，得到的是空数组 `[]`。

### 简单示例

```js
function sum(...nums) {
  return nums.reduce((total, n) => total + n, 0);
}

console.log(sum(1, 2, 3));        // 6
console.log(sum(10, 20));         // 30
console.log(sum());               // 0
```

```js
function introduce(name, age, ...hobbies) {
  console.log(`${name}，${age}岁`);
  console.log('爱好：', hobbies);
}

introduce('小明', 18, '篮球', '编程', '游泳');
// 小明，18岁
// 爱好： ['篮球', '编程', '游泳']
```

### 和 `arguments` 的区别

| 特性              | 剩余参数 `...args`         | `arguments` 对象                       |
| ----------------- | -------------------------- | -------------------------------------- |
| 类型              | 真正的数组                 | 类数组对象                             |
| 能否使用数组方法  | 能（map、filter、reduce…） | 不能直接用，需转换                     |
| 箭头函数中可用    | 可用                       | 不可用（箭头函数没有自己的 arguments） |
| 包含的内容        | 只包含“剩余”的参数         | 包含所有传入的参数                     |
| 严格模式/现代写法 | 推荐使用                   | 逐渐被替代                             |

```js
// 剩余参数是数组
function demo1(...args) {
  console.log(Array.isArray(args)); // true
  console.log(args.map(x => x * 2));
}

// arguments 不是数组
function demo2() {
  console.log(Array.isArray(arguments)); // false
  // arguments.map(...) 会报错
}
```

### 常见用法

1. **收集不定数量的参数**
   ```js
   function max(...numbers) {
     return Math.max(...numbers); // 这里用了展开运算符
   }
   ```

2. **和普通参数混用**
   ```js
   function log(level, ...messages) {
     console.log(`[${level}]`, ...messages);
   }
   log('INFO', '用户登录', 'IP: 192.168.1.1');
   ```

3. **在箭头函数中使用**
   ```js
   const multiply = (...nums) => nums.reduce((a, b) => a * b, 1);
   ```

4. **解构时也能用剩余参数**
   ```js
   const [first, second, ...rest] = [1, 2, 3, 4, 5];
   // first = 1, second = 2, rest = [3, 4, 5]
   ```

### 注意事项

- 剩余参数**必须是最后一个参数**，否则语法错误。
  ```js
  // 错误写法
  function bad(...args, last) {}  // SyntaxError
  ```
- 它收集的是**实际传入的参数**，和函数声明的参数个数无关。
- 和展开运算符（Spread）看起来一样（都是 `...`），但作用相反：
  - 剩余参数：把多个值**收成**数组
  - 展开运算符：把数组**拆成**多个值

```js
// 剩余：收集
function collect(...arr) { return arr; }

// 展开：拆开
const nums = [1, 2, 3];
Math.max(...nums); // 相当于 Math.max(1, 2, 3)
```

### 总结

剩余参数让函数可以优雅地处理不定数量的参数，得到的是真正的数组，写法清晰，也是目前推荐的写法。在需要接收可变参数时，优先使用 `...rest`，而不是老式的 `arguments`。
