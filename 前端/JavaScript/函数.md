
# 1. 函数的本质

1. 函数就是普通的值（一等公民）。你**可以在任何作用域里声明**函数，包括：全局、另一个函数内部、箭头函数、普通函数、对象方法……都可以。**可以赋值**给变量、作为参数传递、作为返回值返回、动态创建。
2. 函数也是对象：拥有属性和方法（如 `length`、`name`、`call`、`apply`、`bind`）。
3. 执行函数时，会创建一个**执行上下文**（Execution Context），包含变量环境、词法环境、`this` 绑定等。

## 2. 定义函数的几种方式

### 2.1 函数声明（Function Declaration）
```js
function add(a, b) {
  return a + b;
}
```
- 特点：**会被提升（hoisting）**。也即在它前面的代码块里也可以访问，整个函数体在作用域内提前可用。
- 适合需要在定义前调用的场景。

### 2.2 函数表达式（Function Expression）
```js
const add = function(a, b) {
  return a + b;
};
```
- 特点：不会被提升（变量提升，但赋值为 `undefined`）。
- 可以是匿名的，也可以命名（命名便于调试和递归）。

### 2.3 箭头函数（Arrow Function，ES6）
```js
const add = (a, b) => a + b;          // 单行隐式返回
const add = (a, b) => { return a + b; }; // 多行
const square = x => x * x;            // 单参数可省略括号
```
- **没有自己的 `this`、`arguments`、`super`、`new.target`**。
- `this` 继承自外层词法作用域（非常适合回调）。
- 不能作为构造函数（不能用 `new`）。
- 更简洁，推荐在现代代码中优先使用。

### 2.4 其他方式
- **方法简写**（对象字面量）：
  ```js
  const obj = {
    add(a, b) { return a + b; }
  };
  ```
- **Function 构造函数**（不推荐，有作用域和性能问题）：
  ```js
  const add = new Function('a', 'b', 'return a + b');
  ```
- **立即执行函数表达式（IIFE）**：
  ```js
  (function() {
    // 私有作用域
  })();
  ```

## 3. 参数与返回值

在JavaScript中调用函数参数的传递直接按照顺序传递即可，不像Python那样搞那么多花样。JavaScript和java一样，参数是按照值来传递，对于基本数据类型，就是值本身，对于引用对象，就是对象的引用值。
>JavaScript中允许传入任意个参数而不影响调用，传入的参数比定义的参数少或者多都不会影响调用

### 参数（Parameters）与实参（Arguments）
- 形参可以有默认值（ES6）：
  ```js
  function greet(name = 'Guest') { ... }
  ```
- 剩余参数（Rest）：
  ```js
  function sum(...nums) { return nums.reduce((a, b) => a + b, 0); }
  ```
- 解构参数：
  ```js
  function print({ name, age }) { ... }
  ```
- `arguments` 对象（类数组）：在普通函数中可用，箭头函数中没有。推荐用 Rest 参数替代。

### 返回值
- 使用 `return`。没有 `return` 或 `return;` 则返回 `undefined`。
- 可以返回任何类型，包括函数（高阶函数）。

# 2. 作用域、闭包与词法环境

- **词法作用域**：函数定义时决定，而非调用时。
- **闭包（Closure）**：函数可以“记住”并访问其定义时的词法环境。内层函数可以访问外层函数定义的所有变量和函数，并且只有这个内层函数一直存在，被它访问的外层变量和函数就不会被销毁，内层函数会一直持有它们的引用。

  ```js
  function createCounter() {
    let count = 0;
    return function() {
      return ++count;
    };
  }
  const counter = createCounter();
  console.log(counter()); // 1
  console.log(counter()); // 2
  ```
- 闭包是实现数据私有化、模块模式、柯里化等的基础。

# 3. `this` 关键字

`this` 的值取决于**调用方式**，而不是定义位置（箭头函数除外）。

| 调用方式              | `this` 指向                  |
|-----------------------|------------------------------|
| 普通函数调用          | 严格模式下 `undefined`，非严格模式 `window`/`global` |
| 方法调用 `obj.method()` | `obj`                       |
| `new` 构造            | 新创建的对象                 |
| `call`/`apply`/`bind` | 显式指定                    |
| 箭头函数              | 继承外层 `this`             |

常用绑定方法：
```js
fn.call(obj, arg1, arg2);
fn.apply(obj, [arg1, arg2]);
const bound = fn.bind(obj);
```




# 4. 最佳实践与常见陷阱

**推荐**：
- 优先使用箭头函数 + `const`/`let`。
- 使用默认参数、Rest、解构。
- 小函数、单一职责。
- 合理使用闭包，避免内存泄漏（注意解除引用）。

**陷阱**：
- 普通函数中的 `this` 丢失（常见于事件回调、定时器）→ 用箭头或 `bind`。
- 闭包中循环变量问题（用 `let` 或 IIFE 解决）。
- 过度使用递归导致栈溢出。
- 把箭头函数当构造函数。
- 混淆提升行为。
