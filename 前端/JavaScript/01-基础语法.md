# 变量声明

```JavaScript
// 推荐写法（ES6+）
let age = 25;           // 可变变量
const PI = 3.14;        // 常量（优先使用）
let name = "张三";

// 旧写法（尽量少用）
var oldVar = "不推荐";
```

**和 Java 的对比**：
- let ≈ Java 的局部变量
- const ≈ final（但对象内容仍可变）
- 没有类型声明，类型是运行时决定的（动态类型）
- var 有函数作用域和变量提升问题，现代代码几乎不用

## 基本数据类型

```javaScript
// 原始类型（Primitive）
let str = "hello";          // 字符串
let num = 42;               // 数字（没有 int/float 区分，都是 Number）
let bool = true;            // 布尔
let empty = null;           // 空值
let notDefined = undefined; // 未定义
let big = 123n;             // BigInt（很大的整数）
let unique = Symbol("id");  // 符号（唯一值）

// 引用(对象)类型
let obj = { name: "张三", age: 25 };  // 对象
let arr = [1, 2, 3];                  // 数组（本质也是对象）
let func = function() {};             // 函数（一等公民）
```


类型判断
```javaScript
typeof 42;          // "number"
typeof "hi";        // "string"
typeof true;        // "boolean"
typeof undefined;   // "undefined"
typeof null;        // "object"（历史遗留坑）
typeof {};          // "object"
Array.isArray([]);  // true
```


## 运算符

```javaScript
// 算术
+ - * / % **（幂运算）

// 比较
===  !==   // 严格相等（推荐，同时比较值和类型）
==   !=    // 宽松相等（会做类型转换，容易出坑）

1 == "1"    // true（宽松）
1 === "1"   // false（严格，推荐永远用 ===）
0 || "默认" // "默认"
null ?? "默认" // "默认"

// 逻辑
&&  ||  !  

// 其他
??          // 空值合并（null 或 undefined 时取右边）
?.          // 可选链（安全访问属性）
```

## 条件与循环

```javaScript
// if
if (age >= 18) {
  console.log("成年");
} else if (age >= 12) {
  console.log("青少年");
} else {
  console.log("儿童");
}

// 三元
let status = age >= 18 ? "成年" : "未成年";

// switch（和 Java 类似，但用 === 比较）
switch (fruit) {
  case "apple":
    console.log("苹果");
    break;
  default:
    console.log("其他");
}

// 循环
for (let i = 0; i < 5; i++) { ... }

while (condition) { ... }

// 数组遍历（更常用）
for (const item of arr) { ... }          // 值
for (const key in obj) { ... }           // 键（对象用）
arr.forEach(item => { ... });
```

##  字符串

- 字符串是零个或多个字符的序列。
- 字符串文字以单引号 (') 或双引号 (") 开始和结束
- JavaScript 字符串是不可变的，这意味着它们在创建后修改将返回新的对象。

```javaScript
// 1. 双引号
let s1 = "Hello";
// 2. 单引号
let s2 = 'Hello';
// 3. 反引号（模板字符串，推荐）
let s3 = `Hello`;

let str = "Hello";
console.log(str.length);     // 5（字符个数）
console.log(str[0]);         // "H"（推荐写法）

```

### 模板字符串

```javaScript
const name = "张三";
const age = 28;

// 传统写法（拼接很麻烦）
const str1 = "我叫" + name + "，今年" + age + "岁。";
// 模板字符串写法
const str2 = `我叫${name}，今年${age}岁。`;
console.log(str2); // 我叫张三，今年28岁。



// 传统写法需要 \n 或字符串拼接，模板字符串天然支持换行

// 传统写法
const html1 = "<div>\n" +
              "  <h1>标题</h1>\n" +
              "  <p>内容</p>\n" +
              "</div>";

// 模板字符串
const html2 = `
<div>
  <h1>标题</h1>
  <p>内容</p>
</div>
`;

console.log(html2);
```

**核心规则**：
- 使用反引号 ` 包裹
- 用 ${表达式} 插入变量或表达式
- ${} 里面可以写任意合法的 JavaScript 表达式
