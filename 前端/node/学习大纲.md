
**Node.js 学习大纲**（适合有 Java 后端基础、正在补全栈的开发者）

### ⁠0.1 ⁠前置准备（1-2天）
- 安装 Node.js（推荐 LTS 版本）和 npm / pnpm / yarn
- 了解 npm 基本使用（init、install、scripts、package.json）
- 简单复习 JavaScript 核心（ES6+）：箭头函数、解构、Promise、async/await、模块化（import/export）
- 推荐工具：VS Code + 常用插件（ESLint、Prettier、Thunder Client）

### ⁠0.2 ⁠Node.js 基础核心（1周）
1. **运行原理**
   - V8 引擎、事件循环（Event Loop）
   - 单线程 + 非阻塞 I/O 模型
   - 与 Java 多线程模型的对比理解

2. **核心模块**
   - `fs`（文件读写，同步/异步）
   - `path`、`os`、`url`
   - `http` / `https`（手写简单服务器）
   - `events`（EventEmitter）
   - `stream`（流的基本使用）
   - `buffer`

3. **模块系统**
   - CommonJS（require / module.exports）
   - ES Modules（import / export）
   - 两者区别与兼容

### ⁠0.3 ⁠异步编程深入（3-5天）
- 回调地狱问题
- Promise 链与错误处理
- async/await 最佳实践
- 错误处理模式（try/catch、统一错误中间件思路）
- 并发控制（Promise.all、allSettled、限制并发）

### ⁠0.4 ⁠Web 开发基础（1.5-2周）
1. **原生 HTTP 服务**
   - 路由处理、请求解析、响应头设置
   - 静态资源服务

2. **Express 框架**（必学入门框架）
   - 路由、中间件机制
   - 请求体解析（body-parser / express.json）
   - 静态文件、模板引擎（可选）
   - 错误处理中间件
   - 简单 RESTful API 实践

3. **进阶框架选择**（二选一深入）
   - **NestJS**（强烈推荐有 Java 背景的人）：装饰器、依赖注入、模块化，风格接近 Spring
   - Koa / Fastify（更轻量，理解中间件和性能）

### ⁠0.5 ⁠数据库与持久化（1周）
- 关系型：MySQL / PostgreSQL + `mysql2` 或 Prisma / TypeORM
- 文档型：MongoDB + Mongoose
- ORM/ODM 使用与原生 SQL 对比
- 连接池、事务基础
- 环境变量管理（dotenv）

### ⁠0.6 ⁠工程化与常用能力（持续）
- TypeScript 在 Node.js 中的使用（强烈建议尽早上 TS）
- 环境区分（development / production）
- 日志（winston / pino）
- 配置管理
- 单元测试（Jest / Vitest）
- 接口测试（Postman / Thunder Client / Supertest）
- 代码规范（ESLint + Prettier）

### ⁠0.7 ⁠进阶与实战能力（2-3周+）
1. **认证与安全**
   - JWT、Session
   - 密码加密（bcrypt）
   - CORS、Helmet、限流、输入校验（zod / joi）

2. **实时通信**
   - WebSocket 基础
   - Socket.IO 实战（聊天室、实时通知）

3. **性能与架构**
   - 集群（cluster）、Worker Threads
   - 缓存（Redis）
   - 消息队列入门（BullMQ 等）
   - 简单微服务拆分思路

4. **部署与运维基础**
   - PM2 进程管理
   - Docker 简单容器化
   - 云服务器 / Serverless 部署概念

### ⁠0.8 ⁠推荐学习路径与项目练习

**阶段目标建议：**

| 阶段 | 目标 | 建议项目 |
|------|------|----------|
| 基础 | 能写简单 HTTP 服务和文件操作 | 命令行小工具、静态文件服务器 |
| 框架 | 熟练用 Express/NestJS 写 API | 用户管理 + CRUD 接口 |
| 全栈雏形 | 前后端联调 | 简易博客 / 待办事项（对接 React） |
| 进阶 | 认证 + 实时 + 数据库 | 简易聊天室 或 任务管理系统 |
| 综合 | 工程化完整项目 | 仿 Express 风格的中型 API 服务 |

### ⁠0.9 ⁠学习资源建议
- 官方文档：nodejs.org（必看）
- 书籍：《深入浅出 Node.js》（朴灵，经典但偏旧，配合新文档）
- 视频：B站搜索「Node.js 最新」+ 官方或高质量教程
- 实践：多写、多看 GitHub 上中小型开源项目

---

**给有 Java 背景的特别建议：**
1. 前期用 Express 快速建立手感，再转到 NestJS（依赖注入、模块、装饰器会非常亲切）。
2. 尽早使用 TypeScript，减少动态类型带来的不适。
3. 重点理解「事件循环」和「非阻塞」，这是和 Java 思维差异最大的地方。
4. 不要过早追求高性能细节，先把业务 API 写熟、工程化做好。
