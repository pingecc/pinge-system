# 全文检索
一种在大量文本数据中快速查找特定词汇的检索技术，基于倒排索引来实现。


### 倒排索引

也是一种索引数据结构，不过是建立 词汇 和 文档ID之间的映射，通过建立词汇索引结构来去寻找文档ID，而不是通过问答ID来去找词汇（正向索引）


1、倒排索引的建立流程：

- 将每一个文档的数据利用算法分词，得到一个个词条
- 创建表，每行数据包括词条、词条所在文档id、位置等信息
- 因为词条唯一性，可以给词条创建索引，例如hash表结构索引

2、基于倒排索引的搜索流程：

1）用户输入条件`"华为手机"`进行搜索。

2）对用户输入内容**分词**，得到词条：`华为`、`手机`。

3）拿着词条在倒排索引中查找，可以得到包含词条的文档id：1、2、3。

4）拿着文档id到正向索引中查找具体文档。


## ES存储概念

### 文档和字段

elasticsearch是面向文档（Document）存储的，可以是数据库中的一条商品数据，一个订单信息。文档数据会被序列化为json格式后存储在elasticsearch中

而Json文档中往往包含很多的**字段（Field）**，类似于数据库中的列。

### 索引和映射
在ES中，索引指的是相同类型的文档（类似传统数据库的表），映射指的是索引中文档字段的约束（类似传统数据库的表结构约束）。

## ES安装

### 分词器

用于分词，
- 在创建倒排索引时指定使用的分词器，对文档分词
- 用户搜索时，会对输入的内容分词

ES默认了一些内置的分词器，也可以额外去下载一些分词器插件。

IK分词器的分词模式？

- ik_smart：智能切分，粗粒度
- ik_max_word：最细切分，细粒度

IK分词器还提供对词条的扩展和禁用

- 利用config目录的IkAnalyzer.cfg.xml文件添加拓展词典和停用词典
- 在词典中添加拓展词条或者停用词条
