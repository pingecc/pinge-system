# 红-绿-重构

单元测试：针对一个函数，写一个测试函数，然后写各种测试用例函数，在测试函数里去调用所有测试用例来测试目标函数的正确性。

```Java
public static void testA() {
    boolean res = false;
    
    res = caseA();
    res = caseB();
    res = caseC();


}
```

单元测试的作用：

- 重构代码的保证，每次对函数进行修改，都运行一下单元测试，测试通过说明重构没问题。最好是每改一小步就运行一下测试用例


集成测试：被测试的 函数有依赖其它函数服务，对这样的函数进行测试就是集成测试，而单元测试的函数是最小单元的函数，没有依赖其它函数服务。
