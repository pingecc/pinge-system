# node
    

[Download NVM](https://www.nvmnode.com/guide/download.html)

1. 下载nvm
    

```Bash
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.5/install.sh | bash
```

> 1. nvm:node version manager node.js版本管理器 本质是一个命令行工具，允许在同一个系统按照和管理多个独立的node.js版本
>     
> 2. 下载node.js时，会附带对应的npm(包管理器，就和Java中的maven一样），用来下载对应的js库，下载和管理对应的项目依赖
>

### 配置淘宝镜像地址
    

查看当前镜像

```Bash
npm config get registry
```

设置淘宝镜像

```Bash
npm config set registry https://registry.npmmirror.com
```

如果想切回之前的官方镜像

```Bash
npm config set registry https://registry.npmjs.org
```
