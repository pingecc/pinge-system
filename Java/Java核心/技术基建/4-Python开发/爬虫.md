# Playwright
    

动态网页：指的是主体内容或者全部内容都需要客户端执行JavaScript代码来计算或渲染的网页。

如果直接requests.get(url) 去请求一个动态网页，你只能拿到那个空的“骨架”HTML，里面没有你想要的实际数据（比如商品信息、评论等）。数据是通过JS后续加载的，然后嵌入到HTML里的。

所以对于动态网页数据的爬取，我们主要有2种放行：

1. 通过分析得到目标数据是调用哪个（哪些）接口地址获取的
    
2. 通过Web自动化工具（Selenium、**Playwright** ）模拟浏览器抓取，
