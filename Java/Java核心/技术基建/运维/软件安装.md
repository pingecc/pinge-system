
# MinIO
## Docker单机
1. 下载

```Bash
docker run -d \
  --name minio \
  -p 9000:9000 \
  -p 9001:9001 \
  -v ~/docker-volumes/minio-data:/data \
  -e "MINIO_ROOT_USER=admin" \
  -e "MINIO_ROOT_PASSWORD=miniopassword123" \
  minio/minio \
  server /data --console-address ":9001"
```

2. 查看启动日志

```Bash
docker logs minio
```

# Redis下载

## mac
1. 下载
```Bash
brew install redis
```

2. 查看安装路径

```Bash
# 查看 Homebrew 安装的 Redis 配置目录 
brew --prefix redis
```


3. 以后台服务方式启动
```Bash
brew services start redis
```

3. 停止redis服务

```Bash
brew services stop redis
```
