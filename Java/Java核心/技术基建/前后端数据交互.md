
# POST请求


## 纯 JSON 数据交互
最常见 API

 🔗 URL

```
POST https://api.example.com/api/users
```

 📤 原始 HTTP 请求

```http
POST /api/users HTTP/1.1
Host: api.example.com
Content-Type: application/json
Accept: application/json
Content-Length: 62

{"name":"Alice","age":30,"email":"alice@example.com"}
```

📥 原始 HTTP 响应

```http
HTTP/1.1 201 Created
Content-Type: application/json
Content-Length: 78

{"id":101,"name":"Alice","age":30,"email":"alice@example.com","createdAt":"2026-01-18T20:00:00Z"}
```

 🖥️ 前端（Axios）

```js
// 发送
const res = await axios.post('/api/users', {
  name: 'Alice',
  age: 30,
  email: 'alice@example.com'
});

// 接收（res.data 即为解析后的 JS 对象）
console.log(res.data.id); // 101
```

 ⚙️ 后端（Spring Boot）

```java
@PostMapping("/api/users")
public ResponseEntity<User> createUser(@RequestBody @Valid User user) {
    User saved = userService.save(user);
    return ResponseEntity.status(HttpStatus.CREATED).body(saved);
}

// User.java（需有 getter/setter）
public class User {
    private Long id;
    private String name;
    private Integer age;
    private String email;
    private LocalDateTime createdAt;
}
```

> ✅ 自动使用 Jackson 反序列化/序列化  
> ❌ 不支持文件（除非 Base64）

##  文件+文本字段上传

标准表单上传

 🔗 URL

```
POST https://api.example.com/api/upload/avatar
```

 📤 原始 HTTP 请求

```http
POST /api/upload/avatar HTTP/1.1
Host: api.example.com
Content-Type: multipart/form-data; boundary=----WebKitFormBoundaryAbc123
Content-Length: 398

------WebKitFormBoundaryAbc123
Content-Disposition: form-data; name="userId"

123
------WebKitFormBoundaryAbc123
Content-Disposition: form-data; name="file"; filename="avatar.jpg"
Content-Type: image/jpeg

ÿØÿà
------WebKitFormBoundaryAbc123--
```

 📥 原始 HTTP 响应

```http
HTTP/1.1 200 OK
Content-Type: application/json
Content-Length: 65

{"url":"https://cdn.example.com/avatars/123.jpg","status":"uploaded"}
```

 🖥️ 前端（Axios）

```js
const formData = new FormData();
formData.append('userId', '123');
formData.append('file', fileInput.files[0]); // File 对象

// ⚠️ 不要设置 Content-Type！让浏览器自动加 boundary
const res = await axios.post('/api/upload/avatar', formData, {
  headers: { 'Content-Type': 'multipart/form-data' } // ❌ 错误！会丢失 boundary
  // 正确做法：省略 headers 或设为 undefined
});

// 正确写法：
const res = await axios.post('/api/upload/avatar', formData);
```

 ⚙️ 后端（Spring Boot）

```java
@PostMapping("/api/upload/avatar")
public R uploadAvatar(
    @RequestParam("userId") Long userId,
    @RequestParam("file") MultipartFile file
) throws IOException {
    if (file.isEmpty()) throw new IllegalArgumentException("File is empty");
    
    String ext = StringUtils.getFilenameExtension(file.getOriginalFilename());
    String objectName = userId + "." + ext;
    
    // 上传到 MinIO / 本地磁盘等
    minioClient.putObject(PutObjectArgs.builder()
        .bucket("avatars")
        .object(objectName)
        .stream(file.getInputStream(), file.getSize(), -1)
        .build());
    
    return R.OK().data("url", "https://cdn.example.com/avatars/" + objectName);
}
```

> ✅ 支持多个文本 + 多个文件  
> ✅ 自动解析文件名、MIME 类型、大小

## 带 JSON 元数据的文件上传

 🔗 URL

```
POST https://api.example.com/api/documents
```

 📤 原始 HTTP 请求

```http
POST /api/documents HTTP/1.1
Host: api.example.com
Content-Type: multipart/form-data; boundary=----CustomBoundary789
Content-Length: 450

------CustomBoundary789
Content-Disposition: form-data; name="metadata"
Content-Type: application/json

{"userId":123,"category":"contract","tags":["legal","signed"]}
------CustomBoundary789
Content-Disposition: form-data; name="file"; filename="nda.pdf"
Content-Type: application/pdf

%PDF-1.4...
------CustomBoundary789--
```

 📥 原始 HTTP 响应

```http
HTTP/1.1 201 Created
Content-Type: application/json
Content-Length: 80

{"docId":"doc_789","storagePath":"contracts/nda_123.pdf","size":24576}
```

 🖥️ 前端（Axios）

```js
const metadata = { userId: 123, category: 'contract', tags: ['legal', 'signed'] };
const file = fileInput.files[0];

const formData = new FormData();
formData.append('metadata', new Blob([JSON.stringify(metadata)], {
  type: 'application/json'
}));
formData.append('file', file);

const res = await axios.post('/api/documents', formData);
```

 ⚙️ 后端（Spring Boot）

```java
@PostMapping("/api/documents")
public ResponseEntity<DocumentResponse> uploadDoc(
    @RequestPart("metadata") DocumentMetadata meta,
    @RequestPart("file") MultipartFile file
) {
    // 保存文件
    String path = storageService.store(file, meta.getUserId());
    
    DocumentResponse resp = new DocumentResponse();
    resp.setDocId("doc_" + System.currentTimeMillis());
    resp.setStoragePath(path);
    resp.setSize(file.getSize());
    
    return ResponseEntity.status(HttpStatus.CREATED).body(resp);
}

// DTO
public class DocumentMetadata {
    private Long userId;
    private String category;
    private List<String> tags;
    // getters/setters
}
```

> 🔑 关键：使用 `@RequestPart` 而非 `@RequestParam`  
> ✅ 结构化元数据 + 高效文件传输

## 普通表单提交（无文件）

🔗 URL

```
POST https://api.example.com/auth/login
```

📤 原始 HTTP 请求

```http
POST /auth/login HTTP/1.1
Host: api.example.com
Content-Type: application/x-www-form-urlencoded
Content-Length: 38

username=admin&password=secret123
```

📥 原始 HTTP 响应

```http
HTTP/1.1 200 OK
Content-Type: application/json
Set-Cookie: SESSION=abc123; Path=/; HttpOnly; Secure
Content-Length: 45

{"token":"eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."}
```

🖥️ 前端（Axios）

```js
const params = new URLSearchParams();
params.append('username', 'admin');
params.append('password', 'secret123');

const res = await axios.post('/auth/login', params, {
  headers: { 'Content-Type': 'application/x-www-form-urlencoded' }
});
```

⚙️ 后端（Spring Boot）

```java
@PostMapping("/auth/login")
public LoginResponse login(
    @RequestParam String username,
    @RequestParam String password
) {
    // 验证逻辑
    String token = jwtService.generate(username);
    return new LoginResponse(token);
}
```

> ✅ 兼容传统 HTML 表单  
> ❌ 不支持文件；值为字符串（需手动转数字/布尔）

## 文件下载（GET）

🔗 URL

```
GET https://api.example.com/download/report.pdf?userId=123
```

 📤 原始 HTTP 请求

```http
GET /download/report.pdf?userId=123 HTTP/1.1
Host: api.example.com
Accept: */*
```

📥 原始 HTTP 响应

```http
HTTP/1.1 200 OK
Content-Type: application/pdf
Content-Length: 102400
Content-Disposition: attachment; filename="Q3_Report_User123.pdf"

<100KB 的 PDF 二进制数据>
```

 🖥️ 前端（Axios）

```js
// 方式1：触发浏览器下载（推荐）
window.open('/download/report.pdf?userId=123');

// 方式2：用 Axios 获取用于预览
const res = await axios.get('/download/report.pdf?userId=123', {
  responseType: 'blob' // 关键！
});
const url = URL.createObjectURL(res.data);
document.getElementById('pdf-viewer').src = url;
```

 ⚙️ 后端（Spring Boot）

```java
@GetMapping("/download/report.pdf")
public void downloadReport(
    @RequestParam Long userId,
    HttpServletResponse response
) throws IOException {
    // 1. 设置响应头
    response.setContentType("application/pdf");
    response.setHeader("Content-Disposition", 
        "attachment; filename=\"Q3_Report_User" + userId + ".pdf\"");
    
    // 2. 获取文件流（从 MinIO / 本地 / DB）
    InputStream fileStream = storageService.getReport(userId);
    
    // 3. 流式写入（避免内存溢出）
    try (OutputStream out = response.getOutputStream()) {
        fileStream.transferTo(out);
    }
}
```

> ✅ 支持大文件（流式）  
> ✅ `Content-Disposition: attachment` → 下载；`inline` → 预览

## 纯二进制文件上传
无字段名，高级场景

🔗 URL

```
PUT https://api.example.com/upload/chunk/789?partNumber=1
```

📤 原始 HTTP 请求

```http
PUT /upload/chunk/789?partNumber=1 HTTP/1.1
Host: api.example.com
Content-Type: application/octet-stream
Content-Length: 5242880

<5MB 的原始二进制数据>
```

 📥 原始 HTTP 响应

```http
HTTP/1.1 200 OK
Content-Type: application/json
Content-Length: 30

{"partETag":"a1b2c3d4e5f6..."}
```

 🖥️ 前端（Axios）

```js
const chunk = file.slice(start, end); // File.slice() 返回 Blob
await axios.put(`/upload/chunk/789?partNumber=1`, chunk, {
  headers: { 'Content-Type': 'application/octet-stream' }
});
```

⚙️ 后端（Spring Boot）

```java
@PutMapping(value = "/upload/chunk/{uploadId}", consumes = "application/octet-stream")
public ChunkResponse uploadChunk(
    @PathVariable String uploadId,
    @RequestParam int partNumber,
    @RequestBody InputStream inputStream
) throws IOException {
    // 读取流并保存分片
    String etag = s3Client.uploadPart(uploadId, partNumber, inputStream);
    return new ChunkResponse(etag);
}
```

> ✅ 用于大文件分片上传、断点续传  
> ❌ 无法获取文件名、MIME 等元信息（需通过 URL 参数传递）






# GET 请求

| 特性            | 说明                                     |
| ------------- | -------------------------------------- |
| 无 Body        | HTTP 规范不允许 GET 请求包含 Body（即使写了，服务器通常忽略） |
| **参数在 URL 中** | 通过 `?key1=value1&key2=value2` 传递       |
| 幂等 & 可缓存      | **多次请求结果相同，可被浏览器/CDN 缓存**              |
| 长度限制          | URL 总长一般 ≤ 2048 字符（取决于浏览器和服务器）         |
| 可见 & 可书签      | 参数暴露在地址栏，不适合敏感数据                       |

> 🔒 **永远不要用 GET 传递密码、token、身份证号等敏感信息！**


## 简单查询

单个或多个基本类型参数

 🔗 URL

```
GET https://api.example.com/api/users?role=admin&status=active&page=1&size=20
```

 📤 原始 HTTP 请求

```http
GET /api/users?role=admin&status=active&page=1&size=20 HTTP/1.1
Host: api.example.com
Accept: application/json
```

 📥 原始 HTTP 响应

```http
HTTP/1.1 200 OK
Content-Type: application/json
Content-Length: 156

{
  "data": [{"id":1,"name":"Alice"},{"id":2,"name":"Bob"}],
  "total": 2,
  "page": 1,
  "size": 20
}
```

 🖥️ 前端（Axios）

```js
const res = await axios.get('/api/users', {
  params: {
    role: 'admin',
    status: 'active',
    page: 1,
    size: 20
  }
});

console.log(res.data.data); // 用户列表
```

> ✅ `axios.get(url, { params: {...} })` 自动拼接查询字符串

 ⚙️ 后端（Spring Boot）

```java
@GetMapping("/api/users")
public PageResult<User> getUsers(
    @RequestParam(defaultValue = "user") String role,
    @RequestParam(required = false) String status,
    @RequestParam(defaultValue = "1") int page,
    @RequestParam(defaultValue = "10") int size
) {
    return userService.findByRoleAndStatus(role, status, page, size);
}
```

> - `@RequestParam` 绑定查询参数
> - `required = false` 表示可选
> - `defaultValue` 提供默认值

## 数组/列表参数
如多选 ID

🔗 URL

```
GET https://api.example.com/api/orders?ids=101&ids=102&ids=103
```

或（部分框架支持）：

```
GET https://api.example.com/api/orders?ids=101,102,103
```

> Spring Boot 默认支持 **重复参数名**（即第一种格式）

 📤 原始 HTTP 请求

```http
GET /api/orders?ids=101&ids=102&ids=103 HTTP/1.1
Host: api.example.com
Accept: application/json
```

 🖥️ 前端（Axios）

```js
// 方式1：数组自动展开为重复参数（Axios 默认行为）
await axios.get('/api/orders', {
  params: { ids: [101, 102, 103] }
});
// → ?ids=101&ids=102&ids=103

// 方式2：手动拼接（不推荐）
// params: { ids: '101,102,103' }
```

 ⚙️ 后端（Spring Boot）

```java
@GetMapping("/api/orders")
public List<Order> getOrdersByIds(
    @RequestParam List<Long> ids  // 自动绑定重复参数
) {
    return orderService.findByIds(ids);
}
```

> ✅ Spring MVC 自动将 `?ids=1&ids=2` 转为 `List<Long>`

## 文件下载
GET 最常见用途之一

 🔗 URL

```
GET https://api.example.com/download/avatar/123.jpg?token=abc123
```

> 注意：元数据（如用户 ID）放在路径，安全令牌放查询参数

 📤 原始 HTTP 请求

```http
GET /download/avatar/123.jpg?token=abc123 HTTP/1.1
Host: api.example.com
Accept: */*
```

 📥 原始 HTTP 响应

```http
HTTP/1.1 200 OK
Content-Type: image/jpeg
Content-Length: 24576
Content-Disposition: inline; filename="avatar_123.jpg"

<JPEG 二进制数据>
```

 🖥️ 前端（Axios）

```js
// 直接用于 <img> 标签（无需 Axios）
<img src="/download/avatar/123.jpg?token=abc123" />

// 或用 Axios 获取用于 Canvas 处理
const res = await axios.get('/download/avatar/123.jpg', {
  params: { token: 'abc123' },
  responseType: 'blob'
});
const url = URL.createObjectURL(res.data);
```

 ⚙️ 后端（Spring Boot）

```java
@GetMapping("/download/avatar/{userId}.jpg")
public void downloadAvatar(
    @PathVariable Long userId,
    @RequestParam String token,
    HttpServletResponse response
) throws IOException {
    // 1. 验证 token
    if (!authService.isValidDownloadToken(token, userId)) {
        response.sendError(HttpStatus.FORBIDDEN.value());
        return;
    }

    // 2. 设置响应头
    response.setContentType("image/jpeg");
    response.setHeader("Content-Disposition", "inline; filename=\"avatar_" + userId + ".jpg\"");

    // 3. 流式输出
    try (InputStream in = storageService.getAvatar(userId);
         OutputStream out = response.getOutputStream()) {
        in.transferTo(out);
    }
}
```

> ✅ GET 是文件下载的标准方法  
> ✅ 使用 `inline`（预览）或 `attachment`（下载）
