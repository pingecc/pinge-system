
# Ajax

全称："Asynchronous JavaScript and XML"，异步的javaScript 和 XML ，在2005年由[杰西·詹姆士·贾瑞特](https://zh.wikipedia.org/wiki/%E5%82%91%E8%A5%BF%C2%B7%E8%A9%B9%E5%A7%86%E5%A3%AB%C2%B7%E8%B3%88%E7%91%9E%E7%89%B9 "杰西·詹姆士·贾瑞特")所提出的**一种Web开发思想**：通过JavaScript 异步与服务器通信，局部更新页面，不刷新整个网页。
1. 和XML有什么关系?：这是因为在当时网页与服务器交换数据的格式主要是`XML`。

2. 关于技术实现：

其实网页的异步通信的能力早在 1999 年就存在了，由微软在它的IE中作为 ActiveX 对象 提供，名为 Microsoft.XMLHTTP，后来随着发展，各个浏览器都开始支持，然后逐渐标准化，统一为 `XMLHttpRequest`对象。

|年份|事件|
|---|---|
|**1999**|微软在 **IE5** 中引入 `Microsoft.XMLHTTP`（ActiveX），首次实现异步通信|
|**2002**|Mozilla 在 **Gecko 1.0**（Firefox 前身）中实现标准 `XMLHttpRequest` 对象|
|**2004**|**Gmail 上线**，大规模展示 Ajax 能力|
|**2005.2**|Jesse James Garrett 发表《Ajax: A New Approach to Web Applications》，正式提出 “Ajax” 概念|
|**2005.3**|**Google Maps 上线**，进一步验证 Ajax 的用户体验优势|
|**2006+**|jQuery（2006）等库简化 Ajax 编程，推动全面 adoption|
后续：
- **2010s**：`fetch()` API 提出（基于 Promise，更现代化）
- **2017+**：`fetch` 被所有现代浏览器支持，逐渐替代 XHR

今天：`XMLHttpRequest` 仍是底层基础，但新项目多用 `fetch` 或 `axios`


3. 总结：
`Ajax`是一种Web开发思想，通过javascript异步与服务器通信，实现局部刷新页面，通过 `XMLHttpRequest` 对象实现，目前主流浏览器都支持这个对象。


4. 注意：XMLHttpRequest 不是 JavaScript 语言本身的规范，**而是由浏览器（更准确地说，是 Web 浏览器的运行环境）提供的 Web API**。
✅ 一、JavaScript 语言 vs 浏览器环境
1. **JavaScript 语言规范（ECMAScript）**
- 由 **ECMA International** 制定，标准叫 **ECMAScript（ES）**。
- 定义了语言的核心语法和功能，例如：
    - 变量、函数、对象、数组
    - `Number`, `String`, `Date`, `JSON`
    - `Promise`, `Map`, `Set`, 箭头函数等
- **不包含**：`document`, `window`, `fetch`, `XMLHttpRequest`, `setTimeout` 等。

> 📌 换句话说：**纯 JavaScript 引擎（如 Node.js、V8、SpiderMonkey）本身不知道什么是 `XMLHttpRequest`**。

---

2. **浏览器提供的 Web APIs**

- 浏览器在 JavaScript 引擎之上，**额外提供了一套宿主环境 API**，用于操作网页、网络、设备等。
- 这些 API 包括：
    - **DOM API**：`document.getElementById`, `element.innerHTML`
    - **BOM API**：`window`, `location`, `navigator`
    - **Network API**：`XMLHttpRequest`, `fetch`, `WebSocket`
    - **Timer API**：`setTimeout`, `setInterval`
    - **Storage API**：`localStorage`, `sessionStorage`

> 🔸 **`XMLHttpRequest` 就属于“浏览器提供的网络 API”**，不是 ECMAScript 标准的一部分。
