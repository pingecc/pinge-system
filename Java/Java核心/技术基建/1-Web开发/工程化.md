#  vue/cli项目工程
项目结构：


	├── node_modules 
	├── public
	│   ├── favicon.ico: 页签图标
	│   └── index.html: 主页面
	├── src
	│   ├── assets: 存放静态资源
	│   │   └── logo.png
	│   │── component: 存放组件
	│   │   └── HelloWorld.vue
	│   │── App.vue: 汇总所有组件
	│   │── main.js: 入口文件
	├── .gitignore: git版本管制忽略的配置
	├── babel.config.js: babel的配置文件
	├── package.json: 应用包配置文件 
	├── README.md: 应用描述文件
	├── package-lock.json：包版本控制文件

1. 创建一个vue项目步骤：
```Bash
#  全局创建vue的脚手架
npm install -g @vue/cli
# 切换到你要创建项目的目录，然后使用命令创建项目
vue create xxx
#  启动项目
npm run serve
```
上述命令执行完之后，控制台打印如下语句，vue启动了一个web服务，第二个是给同局域网的其它人访问

```
App running at:
- Local: http://localhost:8080/
- Network: http://192.168.3.16:8080/
```

> Vue 脚手架隐藏了所有 webpack 相关的配置，若想查看具体的 webpakc 配置，请执行：`vue inspect > output.js`，约定由于配置，一般不会改，直接使用默认的项目结构和配置即可。
> 如果非要改，Vue脚手架额外提供了`vue.config.js`配置文件，具体可以改哪些参考 https://cli.vuejs.org/zh/config/


### main.js
入口文件。
创建应用 → 指定根组件 → 挂载到 DOM。
```javaScript
import Vue from 'vue'  
import App from './App.vue'  
  
Vue.config.productionTip = false  
  
new Vue({  
  render: h => h(App),  
}).$mount('#app')
```

1. 为什么可以直接 `import Vue from 'vue' `? javaScript的模块化不都是需要写具体的路径，引入某个`.js `文件么？
	这是由打包工具（如 Webpack）和包管理器（npm）共同实现的“模块解析机制”。
	当你写：`import Vue from 'vue'`  ，实际上，打包工具（如 Webpack）会按以下顺序查找：
	1. **检查是否是 npm 包**
	    - 因为你没写路径（如 `./xxx` 或 `../xxx`），所以它认为 `'vue'` 是一个 **第三方包名**
	2. **去 `node_modules` 目录下找**
	    - 查找 `node_modules/vue/`
	3. **读取包的入口文件**
	    - 通过 `package.json` 中的字段确定入口：
	```Json
	{ 
	"name": "vue",
	"main": "dist/vue.runtime.common.js", 
	"module": "dist/vue.runtime.esm.js", 
	"unpkg": "dist/vue.js" 
	 }
	```
	4. **最终导入的是 `dist/vue.runtime.esm.js` 这个文件**

2. vue.js与vue.runtime.xxx.js的区别：
    1. vue.js是完整版的Vue，包含：核心功能 + 模板解析器。
    2. vue.runtime.xxx.js是运行版的Vue，只包含：核心功能；没有模板解析器。
    3. 因为vue.runtime.xxx.js没有模板解析器，所以不能使用template这个配置项，需要使用render函数接收到的createElement函数去指定具体内容。
    4. render属性是一个可以接收 `createElement()`函数的对象
    5. ```javaScript
       render: function(createElement) { 
	       return createElement(App)
	   }
       ```

3. 然后默认会从 `punlic`目录下找到 `index.html`，从这个首页里找到 `id=app`这个DOM节点进行挂载。
### vue.config.js

1. 使用vue inspect > output.js可以查看到Vue脚手架的默认配置。
2. 使用vue.config.js可以对脚手架进行个性化定制，详情见：[https://cli.vuejs.org/zh](https://cli.vuejs.org/zh)

|                                 |                             |
| ------------------------------- | --------------------------- |
| 部分                              | 说明                          |
| CommonJS 模块导出语法（Node.js 环境）     | CommonJS 模块导出语法（Node.js 环境） |
| defineConfig(...)               | Vue CLI 提供的类型提示辅助函数（可选，但推荐） |
| { transpileDependencies: true } | 实际配置项                       |
```JavaScript
const { defineConfig } = require('@vue/cli-service')
module.exports = defineConfig({
  transpileDependencies: true,
  // 关闭语法检查
  lintOnSave: false,
})
```
