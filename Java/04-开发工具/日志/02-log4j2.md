# 依赖


```xml
<dependencies>  
    <!-- 日志门面 -->  
    <dependency>  
        <groupId>org.apache.logging.log4j</groupId>  
        <artifactId>log4j-api</artifactId>  
        <version>2.25.4</version> <!-- 截至 2026 年 4 月最新稳定版 -->  
    </dependency>  
  
    <!-- 日志实现 -->  
    <dependency>  
        <groupId>org.apache.logging.log4j</groupId>  
        <artifactId>log4j-core</artifactId>  
        <version>2.25.4</version>  
    </dependency>  
  
    <!-- Log4j2 的 AsyncFile appender 依赖一个叫 Disruptor 的高性能并发库，从 Log4j2 2.7 版本开始x需要显示引入 -->  
    <dependency>  
        <groupId>com.lmax</groupId>  
        <artifactId>disruptor</artifactId>  
        <version>3.4.4</version> <!-- 截至 2026 年最新稳定版 -->  
    </dependency>  
  
  
  
    <dependency>  
        <groupId>org.projectlombok</groupId>  
        <artifactId>lombok</artifactId>  
        <version>1.18.34</version> <!-- 推荐使用最新版 -->  
        <scope>provided</scope> <!-- 只在编译期生效，不打入最终 jar -->    </dependency>  
</dependencies>
```

上面直接使用了log4j2自带的门面实现，当然log4j2也提供了基于slf4j的实现
```xml
<!-- 1. 引入 SLF4J 门面 -->
<dependency>
    <groupId>org.slf4j</groupId>
    <artifactId>slf4j-api</artifactId>
    <version>2.0.13</version>
</dependency>

<!-- 2. 引入 Log4j2 作为 SLF4J 的实现 -->
<dependency>
    <groupId>org.apache.logging.log4j</groupId>
    <artifactId>log4j-slf4j2-impl</artifactId> <!-- 注意：SLF4J 2.x 对应这个 -->
    <version>2.25.4</version>
</dependency>

<!-- 3. 排除其他日志实现（如 Logback） -->
```

## 配置文件

在 src/main/resources目录下创建 log4j2.xml文件，log4j2会默认读取：
```xml
<?xml version="1.0" encoding="UTF-8"?>  
<Configuration status="WARN" monitorInterval="30">  
    <!--  
        status: 控制 Log4j2 内部日志，生产环境建议 WARN 或 ERROR        monitorInterval: 每30秒检查一次配置文件是否更新，实现热重载  
    -->  
  
    <Properties>  
        <!-- 定义全局变量，便于维护 -->  
        <Property name="log-path">logs</Property>  
        <Property name="archive">${log-path}/archive</Property>  
        <Property name="file-name">application</Property>  
        <!-- 日志格式：时间 | 线程 | 日志级别 | Logger名 | 消息 -->  
        <Property name="log-pattern">%d{yyyy-MM-dd HH:mm:ss.SSS} [%t] %-5level %logger{36} - %msg%n</Property>  
    </Properties>  
  
    <Appenders>  
        <!-- ==================== 控制台输出 ==================== -->        <Console name="Console" target="SYSTEM_OUT">  
            <PatternLayout pattern="%highlight{${log-pattern}}{FATAL=red, ERROR=red, WARN=yellow, INFO=green, DEBUG=blue}"/>  
        </Console>  
  
        <!-- ==================== 高性能滚动文件输出 ==================== -->        <!--            RollingRandomAccessFileAppender 基于 NIO 的 RandomAccessFile，  
            性能比普通的 RollingFileAppender 更高，尤其是在高并发写入场景。  
        -->  
        <RollingRandomAccessFile  
                name="FileAppender"  
                fileName="${log-path}/${file-name}.log"  
                filePattern="${archive}/${file-name}-%d{yyyy-MM-dd}-%i.log.gz">  
  
            <PatternLayout pattern="${log-pattern}" />  
  
            <Policies>  
                <!-- 基于时间的滚动策略：每天滚动一次 -->  
                <TimeBasedTriggeringPolicy interval="1" modulate="true"/>  
                <!-- 基于文件大小的滚动策略：单个文件超过100MB时滚动 -->  
                <SizeBasedTriggeringPolicy size="100 MB"/>  
            </Policies>  
  
            <!--  
                DefaultRolloverStrategy:                - max: 保留的归档文件最大数量（按数字索引）  
                - fileIndex: 设置为 "nomax" 可以让索引从1开始递增，而不是循环覆盖  
            -->  
            <DefaultRolloverStrategy max="30" fileIndex="nomax">  
                <!-- 可选：删除超过30天的旧日志 -->  
                <!--                <Delete basePath="${archive}" maxDepth="1">                    <IfLastModified age="30d"/>                </Delete>                -->            </DefaultRolloverStrategy>  
        </RollingRandomAccessFile>  
    </Appenders>  
  
    <Loggers>  
        <!-- ==================== 第三方库日志降噪 ==================== -->        <!-- 避免框架内部DEBUG/INFO日志刷屏 -->  
        <Logger name="org.springframework" level="WARN"/>  
        <Logger name="org.apache" level="WARN"/>  
        <Logger name="io.netty" level="WARN"/>  
  
        <!-- ==================== 根日志器 (Root Logger) ==================== -->        <!--            所有未被上面特定Logger捕获的日志，都会到这里。  
            additivity="false" 确保日志不会同时被父Logger处理（避免重复）。  
        -->  
        <Root level="INFO" additivity="false">  
            <AppenderRef ref="Console"/>  
            <AppenderRef ref="FileAppender"/>  
        </Root>  
    </Loggers>  
</Configuration>
```
## 使用



1、使用lombok注解

```java
import lombok.Log4j2;

@Log4j2
public class UserService {

    public void createUser(String name) {
        log.info("正在创建用户: {}", name);
        log.warn("用户名未验证: {}", name);
        log.error("模拟错误");
    }

    public static void main(String[] args) {
        new UserService().createUser("Alice");
    }
}
```

2、直接使用

```java
package com.example;

import org.apache.logging.log4j.LogManager;
import org.apache.logging.log4j.Logger;

public class App {
    // 获取 Logger 实例（类名作为 logger 名称）
    private static final Logger log = LogManager.getLogger(App.class);

    public static void main(String[] args) {
        log.trace("这是 TRACE 日志");
        log.debug("这是 DEBUG 日志");
        log.info("✅ 这是 INFO 日志");
        log.warn("⚠️ 这是 WARN 日志");
        log.error("❌ 这是 ERROR 日志");
    }
}
```
