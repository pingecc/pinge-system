
# 工作空间

**工作空间（Workspace）就是任务的工作目录**。在任务执行时，给任务指定工作空间，就可以在任务的执行过程中直接读取该工作目录下的文件数据以及产出的文件数据也直接放在这个目录下。




**OpenClaw** 是一个开源的、本地优先的自主 AI Agent 平台，而 **WorkBuddy** 是腾讯基于类似生态推出的商业化、开箱即用的 AI 办公智能体工作台。两者定位不同，适合人群也不同。

### 一、OpenClaw 是什么？

OpenClaw（中文社区常称“龙虾”）是由奥地利开发者 Peter Steinberger 创建的开源自主 AI Agent，MIT 协议。

**核心特点**：
- **本地运行**：安装在你自己的电脑/服务器上，数据、记忆、配置都存在本地（Markdown + YAML 文件），隐私可控。
- **通过消息平台交互**：主要入口是 WhatsApp、Telegram、Discord、Slack、Signal、iMessage 等，你发消息给它，它就去执行。
- **真正能动手**：不只是聊天，而是能读文件、写文件、跑终端命令、控制浏览器、调用 API、管理日历/邮件等。
- **Skill 系统**：用 `SKILL.md` 定义可复用技能，社区有 ClawHub 技能市场（上万个技能）。
- **MCP 支持**：可连接大量外部工具和数据源。
- **模型无关**：可接 Claude、GPT、DeepSeek、Grok、本地 Ollama 等任意模型。
- **可 24/7 运行**：有 heartbeat 机制，能主动监控任务、处理收件箱，不必你一直盯着。

它本质上是一个**开源 Agent Harness**（运行时脚手架）——把大模型变成能长期、自主干活的本地助手。

安装方式主要是命令行（`npm install -g openclaw` 或一键脚本），需要一定技术基础。

### 二、WorkBuddy 是什么？

WorkBuddy 是**腾讯**推出的全场景 AI 办公智能体工作台（也常被叫“腾讯龙虾”），面向职场人，强调“一句话下达任务，自主规划并交付结果”。

**核心特点**：
- **开箱即用**：桌面客户端下载安装即可，几乎零技术门槛。
- **本地 + 云混合**：支持本地文件操作，同时深度绑定腾讯生态（企业微信、腾讯文档、腾讯会议、乐享等）。
- **专家团模式**：内置 100+ 领域专家（运营、设计、数据、开发等），可多专家并行协作。
- **办公场景强**：文档生成、数据分析、PPT/报告制作、邮件起草、批量文件处理、定时自动化等。
- **Skills + MCP**：支持技能市场和 MCP 扩展，部分兼容 OpenClaw 生态。
- **多入口**：桌面客户端 + 微信小程序 + 企业微信等 IM 远程触发。
- **企业级功能**：权限管控、任务审计、团队协作、知识库集成。

它更像是“成品工作台”，把 Agent 能力包装成对普通职场人友好的产品。

### 三、核心对比

| 维度          | OpenClaw                          | WorkBuddy（腾讯）                     |
|---------------|-----------------------------------|---------------------------------------|
| **定位**      | 开源自托管 Agent 框架 / Gateway   | 企业级 / 个人办公 AI 智能体工作台     |
| **开源**      | 完全开源（MIT）                   | 闭源商业产品                          |
| **部署**      | 自行安装（本地/服务器）           | 下载客户端即用，零部署                |
| **上手难度**  | 较高（需命令行、配置模型）        | 极低（会打字就能用）                  |
| **数据隐私**  | 全部本地，可控性强                | 本地文件 + 腾讯云生态                 |
| **模型**      | 任意模型（Claude/GPT/DeepSeek/本地） | 主要国产模型（混元、DeepSeek、Kimi 等） |
| **入口**      | 消息平台为主（Telegram/WhatsApp 等） | 桌面客户端 + 微信/企微                |
| **扩展性**    | 极高（Skills、MCP、插件、二次开发） | 中等（Skills 市场 + MCP，受平台限制） |
| **办公能力**  | 通用强，需自己配置技能            | 针对文档/数据/报告等场景深度优化      |
| **企业功能**  | 需自行搭建                        | 权限、审计、团队协作、知识库完善      |
| **成本**      | 软件免费，只付模型 API 费用       | 有免费额度，企业版按座位收费          |
| **适合人群**  | 开发者、技术极客、注重隐私和定制  | 普通职场人、企业团队、非技术用户      |

### 四、如何选择？

- **选 OpenClaw**，如果你：
  - 有一定技术背景，愿意折腾
  - 想完全掌控数据、自定义工作流
  - 需要接入任意模型和海外消息平台
  - 希望二次开发或深度集成自己的工具

- **选 WorkBuddy**，如果你：
  - 只想快速提升办公效率，不想管技术细节
  - 主要用腾讯系工具（企微、腾讯文档等）
  - 企业需要权限管控和合规
  - 追求“一句话出结果”的低门槛体验

两者并不完全冲突：技术用户可以两个都用（OpenClaw 做深度定制，WorkBuddy 做日常办公）；也有人把 OpenClaw 当底层，WorkBuddy 当面向业务的封装层来理解。

**一句话总结**：  
OpenClaw 是“乐高积木 + 开源引擎”，自由度最高；WorkBuddy 是“组装好的成品车”，开箱即用、办公场景更顺手。
