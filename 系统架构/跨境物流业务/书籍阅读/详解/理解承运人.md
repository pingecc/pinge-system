

承运人指的是国际物流行业里“谁是真正承担运输责任”的定义。

很多人会觉得：

```text
承运人 = 有船/飞机的人
```

但实际上：

在物流法律和行业体系里：

“承运人（Carrier）”不一定必须拥有运输工具。

核心关键是： **“谁对运输结果负责”**

而不是：**“谁亲自开船/开飞机”。**

这才是理解邮政和快递为什么也是 Carrier 的关键。

---

# **一、先理解物流行业里的“承运人”定义**

国际物流中的 Carrier：

本质意思：

与发货人建立运输合同，并承担运输责任的一方。

注意：

关键词：

```text
运输责任
```

而不是：

```text
运输工具所有权
```

---

# **二、举个最简单例子**

例如：

你通过：

DHL

从中国寄文件到美国。

你认为：

DHL 自己有飞机。

但现实里：

很多时候：

DHL：

可能：

- 部分航段用自己的飞机
- 部分航段包机
- 部分航段租用商业航空公司舱位

例如：

```text
深圳
→ 香港
→ 商业航班
→ 美国
→ DHL本地网络
```

但：

你客户关系里：

负责的人是谁？

仍然是：

```text
DHL
```

所以：

DHL 就是：

## **Carrier（承运人）**

---

# **三、为什么“运输责任”比“是否有飞机”更重要？**

因为：

国际物流最核心的问题是：

- 货丢了怎么办
- 延误怎么办
- 海关问题怎么办
- 索赔找谁

所以法律上：

必须有一个：

```text
责任主体
```

这个主体：

就是：

## **Carrier**

---

# **四、邮政为什么也是 Carrier？**

例如：

United States Postal Service

（USPS）

或者：

Japan Post

---

你寄国际包裹：

```text
中国邮政
→ 国际运输
→ 美国 USPS 派送
```

你会发现：

USPS：

并没有自己的国际飞机覆盖全球。

很多国际段：

也是：

- 租舱
- 合作航班
- 联运

但：

它承担：

- 揽收
- 运输组织
- 投递
- 丢件责任

所以：

它仍然是：

## **Carrier**

---

# **五、快递公司为什么也是 Carrier？**

因为：

快递公司：

本质上已经不是：

```text
单纯运输工具公司
```

而是：

## **“端到端运输网络运营商”**

---

例如：

UPS

提供：

```text
揽收
→ 分拨
→ 干线运输
→ 清关
→ 本地配送
→ 签收
```

整个链路。

所以：

UPS 的核心：

不是：

```text
有多少飞机
```

而是：

## **它控制整个物流网络。**

---

# **六、为什么说“邮政/快递是一体化网络”？**

这是核心中的核心。

---

# **一体化网络是什么意思？**

即：

```text
揽收
+
运输
+
分拨
+
清关
+
末端派送
```

由同一个体系组织。

---

例如：

DHL：

```text
DHL收件
→ DHL系统
→ DHL分拨
→ DHL清关
→ DHL配送
```

整个过程：

用户只面对：

```text
一个Carrier
```

---

# **七、如果没有这种一体化网络会怎样？**

书里说：

“如果没有邮政或快递的一体化网络，那么国际航空货物运输则主要采用集中托运……”

这句话非常专业。

它是在讲：

## **传统航空货运模式。**

---

# **八、传统航空货运其实不是“快递模式”**

传统航空货运：

通常：

```text
发货人
→ 货代
→ 航空公司
→ 目的港代理
→ 本地配送
```

这里：

航空公司：

通常只负责：

```text
机场到机场
```

即：

```text
Airport to Airport
```

而不是：

```text
Door to Door
```

---

# **九、什么是“集中托运”？**

这是国际空运的重要概念。

英文：

```text
Consolidation
```

意思：

## **把很多小货拼成大货。**

---

例如：

10个卖家：

每人：

```text
50kg
```

航空公司：

不会单独接。

因为：

太碎片化。

于是：

货代：

把：

```text
500kg
```

拼一起。

再：

统一订舱。

---

# **十、为什么航司通常不直接面对小客户？**

因为：

航空公司核心是：

## **运力运营**

即：

- 飞机
- 航线
- 舱位

它不擅长：

```text
碎片化客户服务
```

例如：

- 小商家
- 地址问题
- 清关资料
- 包裹追踪

所以：

航空公司：

更像：

## **“批发运力商”**

---

# **十一、货代为什么重要？**

因为：

货代：

是：

## **物流市场的组织者**

他们：

- 拼货
- 订舱
- 清关
- 派送
- 谈价格

所以：

书里说：

“市场资讯大多来自货代”

因为：

货代：

最接近：

```text
真实市场需求
```

---

# **十二、快递公司其实是“超级货代 + 自营网络”**

这是关键理解。

例如：

FedEx

本质上：

已经不是：

```text
单纯航空公司
```

而是：

## **一整套物流网络运营系统。**

它：

既：

- 有自己的飞机
- 又有自己的分拨
- 又有自己的配送

所以：

它把：

```text
货代 + 承运 + 配送
```

整合了。

---

# **十三、为什么现代跨境电商依赖快递网络？**

因为：

跨境电商：

订单特点：

```text
小件
高频
碎片化
全球化
```

这种模式：

传统：

```text
航司 + 货代
```

效率太低。

于是：

出现：

## **DHL/UPS/FedEx 这种一体化网络。**

---

# **十四、你可以用“互联网”类比理解**

这个特别容易理解。

---

# **航司/船司**

类似：

## **“底层网络运营商”**

例如：

```text
中国移动
中国电信
```

提供：

```text
网络带宽
```

---

# **货代**

类似：

## **“网络服务集成商”**

负责：

- 整合资源
- 服务客户
- 组织流量

---

# **快递公司**

类似：

## **“完整互联网平台”**

既：

- 有网络
- 有协议
- 有应用层
- 有终端服务

用户：

直接：

```text
一键下单
```

即可。

---

# **十五、从 ERP/TMS 系统角度理解**

系统里：

Carrier：

并不一定是：

```text
真正开飞机的人
```

而是：

## **对整个运输流程负责的人。**

例如：

```text
Carrier:
- UPS
- DHL
- USPS
- FedEx
```

它们：

都承担：

- Tracking
- Label
- Delivery
- Claim
- SLA

责任。

---

# **十六、一句话总结**

邮政和快递之所以也是 Carrier（承运人），并不是因为它们一定拥有全部运输工具，而是因为：

它们作为统一物流网络的运营者，与客户建立运输合同，并对整个运输链路的履约结果承担责任，因此它们在法律和物流体系中属于真正的承运人。
