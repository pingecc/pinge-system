采购业务定义：企业在一定条件下，从供应市场**获取产品或者服务****作为自己的资源**，为满足自身需（比如办公用途）要或保证生产（比如原材料）、销售（贸易型企业直接采购成品销售赚差价）正常开展的一项经营活动。

简单理解，采购就是企业从外部获取资源。采购管理就是描述这一项活动的展开过程。主要包括以下几个：

1）采购业务流程

2）采购价格体系

3）采购费用

4）受托代销

5）采购发票

6）采购结算

# 采购业务流程
    

下面是常见采购业务流程：

**采购计划。**企业根据自身经营情况制定一个采购计划，包括确定采购什么，采购多少，什么时候采购等等。

> 或者不通过采购计划，而是直接通过**请购单，**表示直接由下游部门的请购申请直接询价。比如【生产部门】申请需要「A原材料」，数量1000kg，需在7月30日前到货。转交给【采购部门】

➡️**采购****询价**。有了计划之后，就是寻找供应商将采购计划落地，这个时候一般会货比三家，比如让供应商发一些样品进行比较分析，最后决策，可以通过询价单记录对应供应商的价格情况。

➡️**采购订单****。**当前确定了供应商和价格信息之后，就直接和供应商进行下订单，交定金，这个过程也可以叫做**采购合同**。

➡️**采购到货。**签完合同之后，供应商开始发货，当到货之后，就需要进行**货物签收**，包括质量、数量、包装是否完好等情况，总之确认货物没有问题之后，就确认签收，在 ERP 这边就是确认到货了。

➡️**采购（暂估）入库**。货物验收完毕之后就需要入到仓库，这个时候就需要**确定入库成本，**简单来说，这个入库成本就是记录入库商品的价值（单价、数量、成本费用）等，方便后续财务核算以及销售计算利润等。如果价格未确认（比如到货了还没发票），则暂估成本入账。【**采购退货/换货**】，采购入库后，可能后续发现质量问题，或者其他原因需要进行退货或者换货处理。

➡️**采购结算：**最后一步就是采购结算，企业拿到供应商的货之后，需要支付货款，结算完成之后就相当于采购的流程走完了。

# 采购价格体系
    

在创建采购订单时，需要填写采购的价格，为了更好的控制成本和提高合规性，在 ERP 中会有一套价格体系，精细化的控制这个价格。

例如，在询价完，得到供应商的价格后，录入采购订单时，ERP 会对照已有控价规则校验价格浮动范围，如果超出允许浮动范围，就要：审批或重新询价或者其他流程，总之是为了更好的控制成本和规范价格。

# 采购费用
    

在采购过程中，一般会产生运输费、装卸费、那**这些费用最终是需要计算到成本里面去**。

一般在费用管理中，需要确定费用类型：是采购费用、销售费用、还是管理费用等；接着做对应的费用单子，然后将费用按照一点个的规则，比如按照库存商品单价、金额、重量等平均分摊到成本当中；最后是对整个采购费用发生情况进行分析。

**采购运输费、装卸费等属于“采购附加费用”**，会**计入采购入库的“成本”**，**那这些费用如何进入入库成本？**

  

**✅ 1. 费用已知、随采购发生 →** **采购订单中维护费用明细**

- 在采购订单中填写：
    
    - 商品价格：¥10 × 100 件 = ¥1000
        
    - 运费（供应商代收代付或自付）：¥200
        
- 系统自动入库成本：¥1200
    
    - 即：商品单价按 1200 / 100 = ¥12 计算
        

**✅ 2. 费用后续开票 →** **费用单 + 分摊处理**

ERP 中常用如下处理方式：

1. 财务或采购建“采购费用单”
    
    1. 类型：运费 / 装卸费 / 保费
        
    2. 关联采购单或入库单
        
2. 系统进行费用分摊（自动或手工设定）：
    
    1. 分摊方式：按金额比例（各商品金额比重）、按数量平均、按重量、体积或者手动设定分摊比例
        
3. 分摊后：
    
    1. 更新库存商品的**单位成本**
        
    2. 调整库存资产总额
        
    3. 会计科目：
        
        - 借：库存商品
            
        - 贷：应付账款 / 费用承担方
            
4. 出库时，系统就能基于**“含分摊费用后的实际成本”**进行成本结转。
    

  

**✅ 四、费用不分摊会带来的问题？理解费用分摊对业务以及财务的重要性：**

|   |   |
|---|---|
|问题|后果|
|成本偏低|出库结转成本偏低，利润虚高|
|财务核算不实|库存资产低估|
|成本控制失真|无法准确分析采购成本、供应商议价力|
|会计科目错误|把运费计入销售费用或管理费用会影响利润分部和报表准确性|

#  采购发票
    

采购的发票是供应商开给企业的发票，一般分为普票和专票，上面涵盖发票明细、金额、税额等信息；

在不同采购发票模式下，对应的成本处理方式有所差异：

## **先货后票**

货物已验收入库，但供应商的发票还未开到。这时不能准确知道真实成本（特别是带税价），所以只能**暂估入库成本**，比如依据合同价、历史价等。**等发票来了**，再进行成本调整。这里有 2 种方式，单到回冲和单到补差，

**1、单到回冲（也称红冲再做）**

**✅ 操作流程：**

1. **入库时先按暂估价入账**
    

比如：100 个商品暂估价 ¥10/个，总计 ¥1,000。

2. **发票到后发现实际价格是 ¥12/个**
    

总额应为 ¥1,200。

3. **系统自动做两步：**
    
    1. **红冲原来暂估成本：** -¥1,000（冲销旧入库成本）
        
    2. **按发票价格重新入账：** +¥1,200
        

**✅ 特点：**

- 入库单成本直接替换为发票价；
    
- 会产生两笔会计记录，增加系统操作量；
    
- 常用于成本要求严格、审计要求高的场景。
    

  

**2、单到补差（也叫补差调账）**

**保留原入库记录，只做一个“补差分录”调整实际成本。**

**✅ 操作流程：**

1. **原入库单记账为 ¥1,000（暂估）**
    
2. **发票到后发现应为 ¥1,200**
    
3. **系统自动生成“补差分录”：+¥200**
    
4. 仅调整存货成本、对应的应付账款增加 ¥200。
    

**✅ 特点：**

- **原入库单不动**，更符合业务连续性；
    
- 系统只做一笔差异调整（减少会计处理量）；
    
- 对成本核算的时效性更高；
    
- 更常见于现代 ERP 系统中。
    

## 现货现票

货到时，发票也到了，此时就直接确定了成本

## 先票后货

一般是供应商预售的方式，先打款，过了一段时间再发货，收到货时实际也是确定了实际成本
