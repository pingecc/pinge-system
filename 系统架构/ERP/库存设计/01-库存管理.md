库存管理的本质：

> 库存管理是对企业物料（Material）的数量、位置、状态的动态管理。

换句话说，它回答了三个问题：

1. 有什么（What）：有哪些物料（原材料、半成品、产成品等）。
    
2. 在哪（Where）：这些物料存放在哪个仓库、哪个库位。
    
3. 多少（How much）：每种物料的库存数量、可用量、在途量、预留量等。
    

# 库存业务设计
    

## 主要功能
    

一个标准 ERP 的库存管理模块一般包含以下功能：

|   |   |   |
|---|---|---|
|**功能模块**|**主要作用**|**示例**|
|入库管理（Inbound）|处理物料入库，如采购入库、生产入库、退货入库|供应商送货 → 验收 → 入库|
|出库管理（Outbound）|处理物料出库，如销售出库、领料出库、退料出库|客户订单出库、生产领料|
|库存调拨（Transfer）|仓库间或库位间的内部调拨|A 仓 → B 仓|
|库存盘点（Stocktaking）|定期核对系统库存与实物库存|年末盘点或抽盘|
|库存状态管理（Status）|管理库存的使用状态|可用、冻结、待检、报废等|
|库存预警（Alert）|根据最小/最大库存设定发出警报||

## 库存几个重要“量”
    

库存不仅仅是一个“数量”，在 ERP 中会被细分为几个概念：

|   |   |   |
|---|---|---|
|**名称**|**含义**|**举例**|
|现有库存（On-hand Quantity）|仓库中实际存在的数量|仓库有 100 个|
|在途库存（In-transit Quantity）|已经采购但尚未到货|供应商已发货 50 个|
|预留库存（Reserved Quantity）|已经承诺给客户或生产使用|销售订单占用 30 个|
|可用库存（Available Quantity）|真正可以自由分配的数量|100 - 30 = 70 个|
|冻结库存（Frozen Quantity）|暂时锁定不可用的数量|待检或异常货品 10 个|

这样企业就能实时知道哪些货能卖、哪些货还在路上、哪些货不能动。

# 库存业务流转
    

库存出入库总体逻辑，库存模块中的一切操作都可以归结为一句话：

> **库存 = 期初库存 + 入库 - 出库**

因此，ERP 系统围绕“入库单”、“出库单”、“调拨单”、“盘点单”四种单据，来记录和驱动库存变化。

## 入库流程
    

1️⃣ 入库的典型业务场景

|   |   |
|---|---|
|**场景**|**说明**|
|采购入库|供应商送货，经检验后入库|
|生产入库|生产完毕的成品或半成品入库|
|退货入库|客户退货回仓|
|其他入库|比如盘盈、赠品、借入物料等|

2️⃣ 入库的业务流转

以“采购入库”为例：

采购订单 → 供应商送货 → 采购收货单（质检）→ 采购入库单 → 库存增加

3️⃣ 入库单的核心字段

|   |   |
|---|---|
|**字段**|**含义**|
|单号|系统自动生成唯一编号|
|入库类型|采购入库 / 生产入库 / 退货入库等|
|仓库|指定入库仓库|
|物料信息|入库的物料|
|数量|实际入库数量|
|批次 / 序列号|追溯信息|
|关联单据|如采购订单号|
|制单人 / 审核人|流程追踪|

📊 **入库影响：**

- 库存数量 ↑
    
- 可用库存 ↑
    
- 财务形成入库成本（影响应付账款或生产成本）
    

## 出库流程
    

**1️⃣ 出库的典型业务场景**

|            |              |
| ---------- | ------------ |
| **场景**     | **说明**       |
| **销售出库**   | 产品销售发货       |
| **生产领料出库** | 车间领料使用       |
| **退料出库**   | 生产退回材料       |
| **调拨出库**   | 从一个仓库调往另一个仓库 |
| **其他出库**   | 赠送、报废、盘亏等    |

**2️⃣ 出库的业务流转**

以“销售出库”为例：

销售订单 → 销售发货单 → 销售出库单 → 库存减少 → 财务生成应收账款

**3️⃣ 出库单的核心字段**

|   |   |
|---|---|
|**字段**|**含义**|
|单号|唯一标识|
|出库类型|销售出库 / 领料出库等|
|仓库|出库仓|
|物料编码|出库的物料|
|数量|出库数量|
|关联单据|销售订单号、领料单号等|
|客户 / 部门|发往客户 or 内部部门|
|审核状态|待审核 / 已审核 / 已过账|

📉 **出库影响：**

- 库存数量 ↓
    
- 可用库存 ↓
    
- 财务形成成本结转（如销售成本）
    

# 系统设计
    

在系统设计层面，库存模块往往要维护以下核心表：

|   |   |   |
|---|---|---|
|**表名**|**说明**|**典型字段**|
|物料主数据（Material Master）|定义所有物料信息|编码、名称、单位、类型、成本价|
|仓库表（Warehouse）|管理仓库基本信息|仓库编号、名称、地址|
|库存表（Inventory）|记录每种物料在每个仓库的数量|仓库ID、物料ID、数量、批次号|
|库存流水表（Inventory Transaction）|记录每一次出入库变动|单号、类型（入/出）、数量、时间|
|库存盘点表（Stocktaking）|记录盘点差异||

# 库存管理目标
    

库存管理不是单纯地“减少库存”或“追求零库存”，而是追求库存效率最优。

目标是：

1. 保证供应 —— 不缺料，生产和销售不受影响
    
2. 降低资金占用 —— 不积压，库存周转快
    
3. 提高准确性 —— 账实相符
    
4. 支持决策 —— 为采购计划、生产计划、销售预测提供数据支撑
