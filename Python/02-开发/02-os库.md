# 环境变量

环境变量（Environment Variables）是操作系统提供的一种键值对机制，用来存储配置信息，供程序、脚本和系统本身使用。它们是进程级别的，每个进程都有自己的环境变量副本，子进程会继承父进程的环境变量。



1. 读取环境变量

```python
import os

# 推荐写法（安全）
home = os.getenv('HOME')                  # 不存在返回 None
path = os.getenv('PATH', default='')      # 可指定默认值

# 直接访问（不存在会抛 KeyError）
home = os.environ['HOME']

# 查看所有环境变量
print(os.environ)                         # 类似字典
print(dict(os.environ))                   # 转成普通字典
```



2. 设置环境变量，仅对当前进程有效

```python
# 方式1
os.environ['MY_VAR'] = 'hello'

# 方式2
os.environ.setdefault('MY_VAR', 'default_value')  # 不存在才设置

# 删除
del os.environ['MY_VAR']
# 或
os.environ.pop('MY_VAR', None)
```

> 重要：在 Python 中设置的环境变量只对当前进程及其子进程有效，不会影响系统或其他已经运行的程序，进程结束后自动消失。





## 使用.env来管理环境变量

.env 是一个纯文本文件，用来存放键值对形式的配置：

```
# .env 文件示例
APP_ENV=development
DEBUG=true
SECRET_KEY=your-super-secret-key-here

DB_HOST=localhost
DB_PORT=5432
DB_USER=postgres
DB_PASSWORD=mysecretpassword
DB_NAME=myapp

REDIS_URL=redis://localhost:6379/0
API_KEY=sk-xxxxxxxxxxxxxxxx
```

- 每行一个变量
- 支持 # 注释
- 值两边可以加引号（一般不加也行）
- **不会被执行**，只是简单的文本配置



```python
pip install python-dotenv
```

### 基本使用

```python
from dotenv import load_dotenv
import os

# 加载当前目录下的 .env 文件
load_dotenv()

# 或者明确指定 .env 文件路径（更稳健）
env_path = Path(__file__).resolve().parent / '.env'
load_dotenv(dotenv_path=env_path)


# 之后就可以像普通环境变量一样使用
db_host = os.getenv('DB_HOST')
db_password = os.getenv('DB_PASSWORD')
debug = os.getenv('DEBUG', 'false').lower() == 'true'
```

load_dotenv() 的作用是：把 .env 文件里的内容读取出来，写入当前进程的环境变量中。之后用 os.getenv() 就能读到。





### 多环境配置

项目中通常准备多个文件：

```
.env                # 本地开发用（加入 .gitignore）
.env.example        # 示例文件（提交到 Git，给别人看有哪些变量）
.env.production     # 生产环境（一般不放仓库，放服务器上）
.env.testing        # 测试环境
```



根据环境加载不同文件

````python
from dotenv import load_dotenv
import os

env = os.getenv('APP_ENV', 'development')

if env == 'production':
    load_dotenv('.env.production')
elif env == 'testing':
    load_dotenv('.env.testing')
else:
    load_dotenv('.env')  # 开发环境
````
