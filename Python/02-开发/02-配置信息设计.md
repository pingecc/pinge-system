
在 Python 项目中，配置信息（如数据库密码、API 密钥、调试开关等）常见的配置管理方式包括：

1. **系统环境变量**（`os.getenv`）
2. **`.env` 文件**（开发环境）
3. **配置文件**（YAML、JSON、TOML 等）
4. **云厂商密钥管理服务**（生产环境推荐）


# 使用 os.getenv 

```python
# 读取环境变量，不存在时返回 None  
api_key = os.getenv("API_KEY")  
​
# 读取环境变量，提供默认值
port = os.getenv("PORT", "8000")  

```
​  

# 使用.env 文件 

1. 安装 python-dotenv包，用于加载.env文件
```python
pip install python-dotenv
```

2. 创建 `.env` 文件：
```bash
# 这是注释，字符串无需使用引号
DATABASE_URL=postgresql://admin:secret123@localhost:5432/mydb  
SECRET_KEY=your-super-secret-key  
PORT=8000
```

3. 在程序中读取

```python
from dotenv import load_dotenv  
import os  
load_dotenv()  # 默认加载当前目录的 .env  
​  
db_url = os.getenv("DATABASE_URL")  
port = int(os.getenv("PORT", "8000"))  
```
