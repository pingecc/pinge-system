
# Python模块化整体模型

```python
project/
├── main.py
└── user.py
```

`user.py`

```python
class User:
    def __init__(self, name):
        self.name = name

    def hello(self):
        print(f"Hello, {self.name}")
```

`main.py`

```python
from user import User

user = User("Tom")
user.hello()
```

整个过程：
```text
main.py
   │
   │ from user import User
   ↓
声明依赖
   │
   ↓
Python 模块系统
   │
   ├── ① 解析 import 声明
   │
   ├── ② 根据搜索路径寻找 user
   │
   ├── ③ 加载 user.py
   │
   ├── ④ 执行 user.py
   │
   ├── ⑤ 创建模块对象
   │
   └── ⑥ 从模块对象中取出 User
            │
            ↓
        main.py 使用
```

- 一个 .py 文件就是一个模块。一个含有 **init**.py 的文件夹就是一个包。
- 模块在首次导入时执行并“**单例化**”。

# 模块使用声明

Python提供2种语法来声明使用哪个模块

```python 
import xxx
from xxx import yyy
```

## import module

```python
import user
```

加载 `user` 模块，然后创建对应的模块对象，并在当前作用域建立一个名为 `user` 的引用指向这个模块对象，然后在当前模块里就可以使用 user.xxx 去访问user模块中的标识符（变量，函数、类等等）。

```python
# user.py
class User:
    pass
    
# main.py
import user
u = user.User()
```
## from module import name

```python
from user import User
```

它表达的意思为：
```text
加载 user 模块
        ↓
获取 user.User
        ↓
把 User 绑定到当前模块
```

然后在当前模块中可以直接：
```python
u = User()
```

简单理解，import user 相当于需要整个user模块，而 from user import User 相当于 我要使用 user模块中的User
# 如何找到模块

```python
import user
```

python解释器它又如何知道去哪里找这个user.py呢？ 其实是通过 sys.path 中提供的路径依次进行查找的。

```python 
import sys  
  
for path in sys.path:  
    print(path)
```
sys.path 是 Python 解释器查找模块的路径列表，来源主要有：
1. 脚本所在目录（或当前工作目录）
2. PYTHONPATH 环境变量
3. 标准库目录
4. site-packages（第三方包）

```
├── order/

```


## 引入包中的模块

```python
import 包名.模块名 [as 别名]

from 包名.模块名 import [类 ｜ 变量 ｜ 函数 ｜ *] [as 别名]
```

## `__init__.py`

```python
order/
└── __init__.py
```

 但是现代 Python 支持 **Namespace Package**，因此并不是所有包都必须拥有 `__init__.py`。
