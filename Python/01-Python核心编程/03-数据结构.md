
# 使用in进行集合比较

假设你想知道一个字母是否为元音字母。一种方法是写一个冗长的if语句

```Python
>>> letter = 'o'
>>> if letter == 'a' or letter == 'e' or letter == 'i'
... or letter == 'o' or letter == 'u':
...     print(letter, 'is a vowel')
... else:
...     print(letter, 'is not a vowel')
...o is a vowel
>>>
```

无论什么时候需要像这样进行大量的比较，都可以使用Python的成员关系运算符（membership operator）**in**来代替

```Python
>>> vowels = 'aeiou'
>>> letter = 'o'
>>> letter in vowels
True
>>> if letter in vowels:
    ...     print(letter, 'is a vowel')
    ...o is a vowel
```

in可以用于任何存在成员关系的数据类型：字符串、列表、元组、集合、字典（比较的是key)

# 字符串

所有字符串方法不会修改原字符串（因为字符串是不可变对象），而是返回一个新字符串。
大多数方法支持可选的 `start` 和 `end` 参数，用于指定操作的子字符串范围。
## 不可变序列

字符串本质是一个字符序列，且不可变，意味着：
- 可以像列表一样通过索引访问字符
- 所有字符串方法不会修改原字符串（因为字符串是不可变对象），而是返回一个新字符串。
- 但**不能**通过索引修改某个字符

```python
s = "hello"
print(s[0])      # 'h'  ✓ 可以访问
# s[0] = 'H'     # TypeError: 'str' object does not support item assignment ✗

s = 'H' + s[1:]  # 正确方式，得到新字符串
```

## 创建字符串
 1. 单引号 / 双引号（完全等价，方便嵌套）

```python
s1 = 'hello'
s2 = "hello"
```

>为什么有两种引号字符呢？主要目的是为了创建包含引号字符的字符串。你可以在双引号字符串中加入单引号，或是在单引号字符串中加入双引号：
2. 三引号：多行字符串
```python
s3 = """第一行
第二行
第三行"""
```

3. 从其他类型转换
```python
s4 = str(123)           # "123"
s5 = str([1, 2, 3])     # "[1, 2, 3]"
```

4. 原始字符串（raw string）：会保留字符串内的所有字符，不会进行转义。常用于正则和路径
```python
path = r"C:\Users\name\new_folder"
```


## 常用 API

- 查找：`find()` / `index()` / `count()` / `startswith()` / `endswith()`
- 修改（返回新串）：`replace()` / `strip()` / `split()` / `join()` / `upper()` / `lower()`
- 格式化：`f-string` / `format()` / `%`
- 判断：`isdigit()` / `isalpha()` / `isspace()` 等

**应用场景**：文本处理、解析、模板、日志等。

## 字符串格式化

f-string（Python 3.6+，最推荐）

```python
name = "Alice"
age = 25
print(f"姓名：{name}，年龄：{age}")
print(f"{name=}, {age=}")          # 调试很方便：name='Alice', age=25

# 表达式、格式控制
pi = 3.1415926
print(f"{pi:.2f}")                 # 3.14
print(f"{1000000:,}")              # 1,000,000
print(f"{0.856:.1%}")              # 85.6%
print(f"{42:08d}")                 # 00000042
print(f"{'hello':>10}")            # '     hello'
```

## 字符串拼接

1. 直接用 `+` 完成拼接，对于非字符串类型的对象，需要先转换成字符串类型
    
2. 将两个字面字符串（非字符串变量）一前一后放置，会自动实现拼接：
    

```Python
print('a''b''c''d')
abcd
```

3. 放入圆括号内的字符串会自动拼接
    

```Python
a = ('a''bb'
     'c')
print(a)
abbc
```

**4、使用*重复**

```Python
print('a'*4)
aaaa
```

**4、通过索引或者分片获取字符串指定字符**

字符串本身是字符序列，可以使用[]来获取某个位置的字符。

```Python
letter = "adasdsdjsidisdasasds"
print(letter[2])
print(letter[0])
# 分片[start:end:step]
# start不写，默认是开始，end不写，默认是结束，步长step不写，默认是1
# 还可以将步长值指定为负数，这样可以让Python从右向左反向分片提取
print(letter[:2])
```

**5、字符串格式化**

当拼接的字符串中包含较多变量时，需要方便简洁的表示变量插入的位置：

`f"字符串 {var} "`

从Python 3.8开始，f字符串便有了一种新的快捷写法，如果你想打印变量名及其值，窍门是把=放在f字符串的{}内的名称之后，在调试代码时非常方便。

```Python
>>> f'{thing =}, {place =}'
thing = 'wereduck', place = 'werepond'
```

名称也可以是表达式，会被照原样打印出来：

```Python
>>> f'{thing[-4:] =}, {place.title() =}'
thing[-4:] = 'duck', place.title() = 'Werepond'
```

**4、****input****(提示信息) 获取控制台键盘用户输入**

无论键盘输入什么类型的数据，获取到的永远都是字符串类型。

5、字符串本身可以看作一个存储字符的容器

所以字符串可以支持容器的一些操作，比如获取长度，for 遍历，按照索引取字符、查找指定字符等

6、比较大小，每个字符都有对应的ASCII码值，直接按照这个码值比较大小。

# 列表（List）

**特点**：有序、可变、可重复、支持索引和切片。

## 常用 API

| 操作 | API | 说明 |
|------|-----|------|
| 创建 | `lst = []` / `list()` / `[1, 2, 3]` | |
| 添加 | `append(x)` / `extend(iterable)` / `insert(i, x)` | 末尾添加、合并、指定位置插入 |
| 删除 | `pop([i])` / `remove(x)` / `del lst[i]` / `clear()` | 弹出、按值删除、按索引删除 |
| 查找 | `index(x)` / `count(x)` / `in` | 找位置、计数、判断存在 |
| 排序 | `sort(key=None, reverse=False)` / `sorted()` | 原地排序 / 返回新列表 |
| 反转 | `reverse()` / `lst[::-1]` | |
| 切片 | `lst[start:stop:step]` | 强大切片操作 |
| 其他 | `len()` / `min()` / `max()` / `sum()` / `copy()` | |

**时间复杂度（平均）**：
- 末尾增删：O(1)
- 中间插入/删除：O(n)
- 查找：O(n)
- 索引访问：O(1)

## 应用场景
- 需要动态增删的有序数据（如待办事项、消息队列的简单实现）
- 需要频繁索引访问
- 作为栈（`append` + `pop`）或队列的简单实现（效率不高）
- 数据预处理、临时收集结果

```python
# 示例：栈
stack = []
stack.append(1)
stack.append(2)
print(stack.pop())  # 2
```

# 2. 元组（Tuple）

**特点**：有序、不可变、可重复、可哈希（元素都可哈希时）。

## 常用 API

| 操作 | API | 说明 |
|------|-----|------|
| 创建 | `t = (1, 2)` / `tuple()` / `1, 2` | 单元素必须加逗号 `(1,)` |
| 访问 | `t[i]` / `t[start:stop]` | 支持索引和切片 |
| 查找 | `index(x)` / `count(x)` / `in` | |
| 解包 | `a, b = t` | 非常常用 |
| 其他 | `len()` / `min()` / `max()` | |

**注意**：没有 `append`、`remove` 等修改方法。

## 应用场景
- 作为字典的键（因为可哈希）
- 函数返回多个值
- 保护数据不被修改（配置、常量）
- 坐标、RGB 等固定结构数据
- `namedtuple`（见后）的基础

```python
point = (3, 4)
x, y = point
```

# 3. 字典（Dict）

**特点**：无序（Python 3.7+ 保持插入顺序）、键唯一、值可变、键必须可哈希。

## 常用 API

| 操作 | API | 说明 |
|------|-----|------|
| 创建 | `{}` / `dict()` / `dict.fromkeys()` | |
| 访问 | `d[key]` / `d.get(key, default)` | `get` 更安全 |
| 添加/修改 | `d[key] = value` / `update()` / `setdefault()` | |
| 删除 | `pop(key)` / `popitem()` / `del` / `clear()` | |
| 视图 | `keys()` / `values()` / `items()` | 动态视图 |
| 其他 | `in` / `len()` / `copy()` | |

**时间复杂度（平均）**：查找、插入、删除均为 **O(1)**（哈希表）。

## 应用场景
- 计数、缓存、配置映射
- 快速查找（比列表快很多）
- 分组、聚合数据
- 实现稀疏矩阵、图的邻接表
- JSON 数据的天然对应

```python
# 计数
from collections import Counter  # 更推荐
cnt = {}
for x in data:
    cnt[x] = cnt.get(x, 0) + 1
```

# 4. 集合（Set）

**特点**：无序、元素唯一、可变（`frozenset` 不可变）、元素必须可哈希。

## 常用 API

| 操作 | API | 说明 |
|------|-----|------|
| 创建 | `set()` / `{1, 2, 3}` | 空集合必须用 `set()` |
| 添加 | `add(x)` / `update(iterable)` | |
| 删除 | `remove(x)` / `discard(x)` / `pop()` / `clear()` | `discard` 不存在不报错 |
| 集合运算 | `\|` / `&` / `-` / `^` | 并、交、差、对称差 |
| 判断 | `in` / `issubset()` / `issuperset()` / `isdisjoint()` | |
| 其他 | `len()` | |

**时间复杂度（平均）**：增删查均为 **O(1)**。

## 应用场景
- 去重（最常用）
- 成员快速判断（比列表快）
- 集合运算（交集、并集等）
- 数学集合问题、标签系统

```python
# 去重并保持顺序（用 dict）
unique = list(dict.fromkeys(lst))
# 纯去重
unique = list(set(lst))
```
