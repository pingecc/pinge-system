
# 使用in进行集合比较

假设你想知道一个字母是否为元音字母。一种方法是写一个冗长的if语句

```Python
>>> letter = 'o'
>>> if letter == 'a' or letter == 'e' or letter == 'i'
... or letter == 'o' or letter == 'u':
...     print(letter, 'is a vowel')
... else:
...     print(letter, 'is not a vowel')
...o is a vowel
>>>
```

无论什么时候需要像这样进行大量的比较，都可以使用Python的成员关系运算符（membership operator）**in**来代替

```Python
>>> vowels = 'aeiou'
>>> letter = 'o'
>>> letter in vowels
True
>>> if letter in vowels:
    ...     print(letter, 'is a vowel')
    ...o is a vowel
```

in可以用于任何存在成员关系的数据类型：字符串、列表、元组、集合、字典（比较的是key)

# 字符串

所有字符串方法不会修改原字符串（因为字符串是不可变对象），而是返回一个新字符串。
大多数方法支持可选的 `start` 和 `end` 参数，用于指定操作的子字符串范围。
## 不可变序列

字符串本质是一个字符序列，且不可变，意味着：
- 可以像列表一样通过索引访问字符
- 所有字符串方法不会修改原字符串（因为字符串是不可变对象），而是返回一个新字符串。
- 但**不能**通过索引修改某个字符

```python
s = "hello"
print(s[0])      # 'h'  ✓ 可以访问
# s[0] = 'H'     # TypeError: 'str' object does not support item assignment ✗

s = 'H' + s[1:]  # 正确方式，得到新字符串
```

## 创建字符串
 1. 单引号 / 双引号（完全等价，方便嵌套）

```python
s1 = 'hello'
s2 = "hello"
```

>为什么有两种引号字符呢？主要目的是为了创建包含引号字符的字符串。你可以在双引号字符串中加入单引号，或是在单引号字符串中加入双引号：
2. 三引号：多行字符串
```python
s3 = """第一行
第二行
第三行"""
```

3. 从其他类型转换
```python
s4 = str(123)           # "123"
s5 = str([1, 2, 3])     # "[1, 2, 3]"
```

4. 原始字符串（raw string）：会保留字符串内的所有字符，不会进行转义。常用于正则和路径
```python
path = r"C:\Users\name\new_folder"
```



## 字符串格式化

f-string（Python 3.6+，最推荐）

```python
name = "Alice"
age = 25
print(f"姓名：{name}，年龄：{age}")
print(f"{name=}, {age=}")          # 调试很方便：name='Alice', age=25

# 表达式、格式控制
pi = 3.1415926
print(f"{pi:.2f}")                 # 3.14
print(f"{1000000:,}")              # 1,000,000
print(f"{0.856:.1%}")              # 85.6%
print(f"{42:08d}")                 # 00000042
print(f"{'hello':>10}")            # '     hello'
```

## 字符串拼接

1. 直接用 `+` 完成拼接，对于非字符串类型的对象，需要先转换成字符串类型
    
2. 将两个字面字符串（非字符串变量）一前一后放置，会自动实现拼接：
    

```Python
print('a''b''c''d')
abcd
```

3. 放入圆括号内的字符串会自动拼接
    

```Python
a = ('a''bb'
     'c')
print(a)
abbc
```

**4、使用*重复**

```Python
print('a'*4)
aaaa
```

**4、通过索引或者分片获取字符串指定字符**

字符串本身是字符序列，可以使用[]来获取某个位置的字符。

```Python
letter = "adasdsdjsidisdasasds"
print(letter[2])
print(letter[0])
# 分片[start:end:step]
# start不写，默认是开始，end不写，默认是结束，步长step不写，默认是1
# 还可以将步长值指定为负数，这样可以让Python从右向左反向分片提取
print(letter[:2])
```

**5、字符串格式化**

当拼接的字符串中包含较多变量时，需要方便简洁的表示变量插入的位置：

`f"字符串 {var} "`

从Python 3.8开始，f字符串便有了一种新的快捷写法，如果你想打印变量名及其值，窍门是把=放在f字符串的{}内的名称之后，在调试代码时非常方便。

```Python
>>> f'{thing =}, {place =}'
thing = 'wereduck', place = 'werepond'
```

名称也可以是表达式，会被照原样打印出来：

```Python
>>> f'{thing[-4:] =}, {place.title() =}'
thing[-4:] = 'duck', place.title() = 'Werepond'
```
