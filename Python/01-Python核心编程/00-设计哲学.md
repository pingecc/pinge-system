Python是一门**多范式**，高级**动态解释型**编程语言。

## 一切皆对象

❝ Everything is an object, and objects are immutable unless explicitly mutable ❞

**1、在 Python 中，所有的东西都是对象**，包括：int, str, list, 函数、类、模块、异常、甚至代码块和类型本身。

在Python中，对象是至少包含以下内容的数据块：

- 类型，定义了可以执行什么操作
- 唯一的id，用于区分其他对象；
- 与类型一致的值；
- 引用计数，用于跟踪该对象的使用频率。


**2、而Python中的对象又分为可变和不可变：**

1）不可变指的是**对象内容不可变**，对原有对象进行某些操作时实际上不会对原有对象的内容进行修改，而是创建一个新的对象返回。Python 的内建核心类型（int, float, str, tuple, bytes, frozenset）都是不可变的，是有意为之，确保对象一旦创建就安全、可哈希、可缓存。

```Python
# 创建 "abc"对象，并返回引用赋值给 a
a = "abc"
# 创建 3 对象，并返回引用赋值给 a，并不是直接对变量a原指向的对象的值进行修改
# 因为不可修改
a = 3
```

所以Python在进行大量数据的数值操作，效率远低于 C/Java，因为不断赋值，需要不断创建新对象，而即使像 int ，str等对象都是堆上的完整结构体，开销比 C 的一个字节数组大得多；对于大量数值操作一般借助专门的库来加速，比如numpy。

2）list, dict, set 这些类型是为了解决实际需要的“可变结构”而明确设计为可变的。

3、查看对象的常用函数

1）`type()` ：查看对象的类型

2）对象之间的转换：`int(x) float(x) str(x)`

3）查看对象有哪些属性和方法：dir(obj)

# 协议

在 Python 中，

协议 = 一组方法规范，不要求继承某个类，只要“像”就行。这种思想也叫做“鸭子类型”：“如果它走起来像鸭子，叫起来像鸭子，那它就是鸭子。”

也即Python 这种动态语言的设计理念是“**不关心对象的类型，只在乎有没有调用的方法/属性**”。

所以下面这些都合法（假设都有 quack() 方法）：

```Python
class Duck:
    def quack(self): print("Quack!")

class Person:
    def quack(self): print("I'm pretending to be a duck!")

def quack(thing):
    thing.quack()
    
    
quack(Duck())     # 输出 Quack!
quack(Person())   # 输出 I'm pretending to be a duck!
```

Python 中很多内建能力就是靠协议来识别的，例如：

- 可迭代协议 → 实现 iter() 或 getitem() ，
- 可调用协议 → 实现 call()
- 可作为路径使用 → 实现 fspath()
    

### 迭代协议

一个对象实现了iter()方法，这个方法返回一个迭代器对象，并且这个迭代器对象实现了iter()和next()方法，且该迭代器中的iter()返回了自己，那么我们称这样的一个**对象是可迭代**的，可以直接基于for循环进行遍历。

为什么要求迭代器和可迭代对象都实现iter()方法？这是为了更好的的灵活和一致的接口调用，当进行传参时无论是拿到了一个可迭代对象还是一个迭代器，都可以直接调用 iter(obj)，并保证得到一个迭代器

```python
for item in iterable:
    ...
# for 循环的本质
it = iter(iterable)  # 第一步：调用 iterable.__iter__()
while True:
    try:
        item = next(it)  # 第二步：调用 it.__next__()
        ...
    except StopIteration:
        break
```
