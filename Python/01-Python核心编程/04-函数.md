

## 1. 基本定义与调用

```python
def greet(name):  
    """简单问候函数"""  
    return f"Hello, {name}!"  
​  
print(greet("Alice"))   # Hello, Alice!
```

**对比 Java：**

- 用 `def` 定义，不需要写返回类型和访问修饰符。
- 没有方法重载（同名函数后面会覆盖前面的）。
- 函数体靠缩进（通常 4 个空格），没有 `{}`。


# 2. 参数

## 位置参数 + 默认参数

```python
def create_user(name, age=18, city="Beijing"):  
    return {"name": name, "age": age, "city": city}  
​  
print(create_user("Bob"))                    # 只用位置参数  
print(create_user("Charlie", 25))            # 覆盖 age  
print(create_user("Diana", city="Shanghai")) # 关键字参数（跳过 age）
```

**注意**：有默认值的参数必须放在没有默认值的参数后面。

## 可变位置参数 `*args`常用

对传入的参数自动转成列表

```python
def sum_all(*numbers):  
    total = 0  
    for n in numbers:  
        total += n  
    return total  
​  
print(sum_all(1, 2, 3, 4))   # 10
```

## 可变关键字参数 `**kwargs`

对传入的参数自动转成 字典。

```python
def print_info(**kwargs):  
    for key, value in kwargs.items():  
        print(f"{key}: {value}")  
​  
print_info(name="Eve", age=30, role="dev")
```


 综合示例（推荐写法）

```python
def process(a, b, *args, c=10, **kwargs):  
    print(f"a={a}, b={b}, c={c}")  
    print("args:", args)  
    print("kwargs:", kwargs)  
​  
process(1, 2, 3, 4, 5, c=20, x=100, y=200)
```

调用时参数顺序规则：**位置参数 → *args → 关键字参数 →** kwargs**。

# 3. 返回值

- 可以返回任意类型，也可以返回多个值（实际是返回一个元组）。    
- 不写 `return` 默认返回 `None`。
    

```python
def divide(a, b):  
    if b == 0:  
        return None, "除数不能为0"   # 多返回值  
    return a / b, "成功"  
​  
result, msg = divide(10, 2)  
print(result, msg)   # 5.0 成功

```
**对比 Java**：不需要定义返回类型，也没有 checked exception 强制处理。

## 1. 函数作为**参数**

 场景一：策略模式 / **可配置行为**（类似 Java 策略模式）
 >通过传入函数来指定行为
 
```python
def calculate(price, discount_func):
    """根据不同的折扣策略计算最终价格"""
    return discount_func(price)

# 各种折扣策略
def no_discount(price):
    return price

def percent_discount(price):
    return price * 0.8          # 8折

def vip_discount(price):
    return price * 0.7 if price > 100 else price

# 使用
print(calculate(200, no_discount))      # 200
print(calculate(200, percent_discount)) # 160
print(calculate(200, vip_discount))     # 140
```

 场景二：回调 / 事件处理（日志、通知、钩子）
 
```python
def process_order(order_id, on_success, on_failure):
    """处理订单，成功或失败时调用对应回调"""
    try:
        # 模拟业务逻辑
        if order_id > 0:
            print(f"订单 {order_id} 处理成功")
            on_success(order_id)
        else:
            raise ValueError("无效订单")
    except Exception as e:
        on_failure(order_id, str(e))

def success_handler(order_id):
    print(f"发送成功通知给用户，订单号：{order_id}")

def failure_handler(order_id, error):
    print(f"记录错误日志：订单 {order_id} 失败，原因：{error}")

process_order(1001, success_handler, failure_handler)
process_order(-1, success_handler, failure_handler)
```

 场景三：高阶函数（类似 Java Stream 的 map / filter）
 
```python
users = [
    {"name": "Alice", "age": 25},
    {"name": "Bob", "age": 17},
    {"name": "Charlie", "age": 30},
]

# 过滤成年用户
adults = list(filter(lambda u: u["age"] >= 18, users))

# 提取名字
names = list(map(lambda u: u["name"], adults))
print(names)  # ['Alice', 'Charlie']
```


## 2. 函数作为**变量**

 场景一：动态选择处理函数（路由 / 命令分发）
```python
def create_user(data):
    print("创建用户:", data)

def update_user(data):
    print("更新用户:", data)

def delete_user(data):
    print("删除用户:", data)

# 把函数存进字典（类似路由表）
handlers = {
    "create": create_user,
    "update": update_user,
    "delete": delete_user,
}

action = "update"
data = {"id": 1, "name": "Tom"}

# 动态调用
handler = handlers.get(action)
if handler:
    handler(data)          # 输出：更新用户: {'id': 1, 'name': 'Tom'}
```

 场景二：临时保存函数引用（延迟执行 / 配置）
```python
def send_email(to, content):

def send_sms(to, content):
    print(f"发送短信给 {to}: {content}")

# 根据配置选择通知方式
notify = send_email if True else send_sms   # 函数赋值给变量

notify("user@example.com", "您的订单已发货")
```

## 3. 函数作为**返回值**（闭包 / 工厂）

 场景一：闭包实现“带状态的函数”
```python
def make_counter(start=0):
    count = start

    def counter():
        nonlocal count
        count += 1
        return count

    return counter          # 返回一个函数

c1 = make_counter()
c2 = make_counter(100)

print(c1())  # 1
print(c1())  # 2
print(c2())  # 101
print(c1())  # 3
```

 场景二：装饰器工厂（最经典的应用）
```python
def retry(times=3):
    """返回一个装饰器，用于自动重试"""
    def decorator(func):
        def wrapper(*args, **kwargs):
            for i in range(times):
                try:
                    return func(*args, **kwargs)
                except Exception as e:
                    print(f"第 {i+1} 次失败: {e}")
                    if i == times - 1:
                        raise
        return wrapper
    return decorator

@retry(times=3)
def unstable_api():
    import random
    if random.random() < 0.7:
        raise ConnectionError("网络抖动")
    return "成功获取数据"

print(unstable_api())
```

场景三：权限校验装饰器（后端常用）
```python
def require_role(role):
    def decorator(func):
        def wrapper(user, *args, **kwargs):
            if user.get("role") != role:
                raise PermissionError(f"需要 {role} 权限")
            return func(user, *args, **kwargs)
        return wrapper
    return decorator

@require_role("admin")
def delete_user(user, user_id):
    print(f"管理员 {user['name']} 删除了用户 {user_id}")

admin = {"name": "Alice", "role": "admin"}
normal = {"name": "Bob", "role": "user"}

delete_user(admin, 1001)      # 正常执行
# delete_user(normal, 1001)  # 抛出 PermissionError
```


# 5. Lambda（匿名函数）


Lambda 是 Python 中创建**匿名函数**的简洁语法，适合写**简单的、一次性的小函数**。它本质上是一个表达式，而不是语句。

 1. 基本语法

```python
lambda 参数1, 参数2, ... : 表达式
```

- 只能写**一个表达式**（不能写多行语句、不能有 `if-else` 块、循环、赋值等）。
- 表达式的结果会自动作为返回值。
- 不需要写 `return`。

```python
# 普通函数（def）
def add(x, y):
    return x + y

# 等价的 Lambda
add = lambda x, y: x + y

print(add(3, 5))   # 8
```


 2. 与 Java Lambda 的对比

| 特性               | Java Lambda                          | Python Lambda                       |
|--------------------|--------------------------------------|-------------------------------------|
| 语法               | `(x, y) -> x + y`                    | `lambda x, y: x + y`                |
| 是否必须赋值/传参  | 通常赋给函数式接口                   | 可以直接赋值或作为参数              |
| 能否多语句         | 可以用 `{}` 写多语句                 | **只能写单个表达式**                |
| 返回值             | 单表达式可省略 return                | 表达式结果自动返回                  |
| 类型               | 强类型（函数式接口）                 | 动态类型                            |
| 常见用途           | Stream、Comparator、回调             | map/filter/sorted、回调、简单策略   |

Python 的 Lambda 更轻量，但功能也更受限。

---

## 1. 常见使用场景

 场景一：配合 `sorted`、`max`、`min` 做自定义排序/比较

```python
users = [
    {"name": "Alice", "age": 25, "score": 88},
    {"name": "Bob", "age": 30, "score": 95},
    {"name": "Charlie", "age": 22, "score": 78},
]

# 按年龄升序
sorted_by_age = sorted(users, key=lambda u: u["age"])

# 按分数降序
sorted_by_score = sorted(users, key=lambda u: -u["score"])

# 多条件排序：先按分数降序，再按年龄升序
sorted_multi = sorted(users, key=lambda u: (-u["score"], u["age"]))

print([u["name"] for u in sorted_by_score])
# ['Bob', 'Alice', 'Charlie']
```

这是 Lambda 在后端代码中**最高频**的用法之一。

场景二：配合 `map`、`filter`

```python
nums = [1, 2, 3, 4, 5, 6]

# 每个数平方
squares = list(map(lambda x: x ** 2, nums))
# [1, 4, 9, 16, 25, 36]

# 过滤偶数
evens = list(filter(lambda x: x % 2 == 0, nums))
# [2, 4, 6]

# 实际业务例子：提取用户 ID 列表
user_ids = list(map(lambda u: u["id"], users))
```

现代 Python 更推荐用**列表推导式**替代简单的 map/filter：

```python
squares = [x ** 2 for x in nums]
evens = [x for x in nums if x % 2 == 0]
```

但在需要传递函数对象的场景下，Lambda 仍然很有用。

 场景三：作为回调 / 简单策略

```python
def process(data, transform):
    return transform(data)

# 直接传 Lambda
result1 = process(10, lambda x: x * 2)          # 20
result2 = process("hello", lambda s: s.upper()) # HELLO
```

 场景四：在装饰器或高阶函数中临时使用

```python
operations = {
    "add": lambda x, y: x + y,
    "mul": lambda x, y: x * y,
    "max": lambda x, y: x if x > y else y,
}

print(operations["add"](3, 4))   # 7
print(operations["mul"](3, 4))   # 12
```

 场景五：配合 `reduce`（需要从 functools 导入）

```python
from functools import reduce

nums = [1, 2, 3, 4, 5]
total = reduce(lambda acc, x: acc + x, nums, 0)  # 15
```



# 6. 作用域

1. **尽量少用 `global`**，全局状态难维护。
2. 需要共享状态时，优先考虑**类**或**闭包**。
3. 嵌套函数修改外层变量时，明确写 `nonlocal`。
4. 循环中创建函数时，注意用默认参数固化变量值。
5. 默认参数永远不要用可变对象（`list`、`dict`、`set`）。



## 1. LEGB 规则（变量查找顺序）

当访问一个变量时，Python 按以下顺序查找：

1. **L**ocal（局部作用域）
2. **E**nclosing（嵌套函数的外层函数作用域）
3. **G**lobal（全局作用域）
4. **B**uilt-in（内置作用域）

找到就停止，找不到就抛出 `NameError`。

```python
x = "global"          # Global

def outer():
    x = "enclosing"   # Enclosing

    def inner():
        x = "local"   # Local
        print(x)      # 输出 local

    inner()
    print(x)          # 输出 enclosing

outer()
print(x)              # 输出 global
```

---

## 2. 局部作用域（Local）

函数内部定义的变量，只在函数内部可见。

```python
def func():
    a = 10          # 局部变量
    print(a)

func()
# print(a)          # NameError: name 'a' is not defined
```

**注意**：函数的参数也是局部变量。

```python
def func(x):        # x 是局部变量
    print(x)

func(100)
```

---

## 3. 全局作用域（Global）

模块级别定义的变量属于全局作用域。

```python
count = 0           # 全局变量

def increment():
    # count += 1    # 错误！会被当成局部变量，导致 UnboundLocalError
    pass
```

 修改全局变量：必须使用 `global` 声明

```python
count = 0

def increment():
    global count
    count += 1

increment()
increment()
print(count)        # 2
```

**对比 Java**：
- Java 的成员变量用 `this.xxx` 访问，没有 `global` 这种关键字。
- Python 默认**只读**全局变量，想修改必须显式声明。

---

## 4. 嵌套作用域（Enclosing）与 `nonlocal`

当存在嵌套函数时，内层函数可以访问外层函数的变量，这就是 **闭包** 的基础。

```python
def outer():
    x = 10

    def inner():
        print(x)    # 可以读取外层的 x

    inner()

outer()             # 10
```

 修改外层函数的变量：使用 `nonlocal`

```python
def outer():
    x = 10

    def inner():
        nonlocal x
        x += 1
        print("inner:", x)

    inner()
    print("outer:", x)

outer()
# 输出：
# inner: 11
# outer: 11
```

**对比**：
- `global`：修改**模块级**变量
- `nonlocal`：修改**最近的外层函数**变量（不能是全局）

```python
x = 100             # 全局

def outer():
    x = 10          # 外层

    def inner():
        # global x      # 会修改全局的 100
        nonlocal x      # 修改外层的 10
        x += 1
        print(x)

    inner()
    print("outer x:", x)

outer()
print("global x:", x)
```

## 5. 内置作用域（Built-in）

Python 内置的名字，如 `print`、`len`、`range`、`Exception` 等，都在内置作用域。

```python
print(len([1, 2, 3]))     # 正常使用内置函数

# 可以临时覆盖（但不推荐）
def len(x):
    return "被覆盖了"

print(len([1, 2, 3]))     # 被覆盖了
```
